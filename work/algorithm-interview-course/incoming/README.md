# 课程源材料占位说明

此目录用于本机保存用户提供的原始课程材料。当前课程包含 67 个 MP4 视频和 3 篇 Markdown 文本教程；这些源材料均不纳入 Git，也不得由归档过程移动、覆盖或重新编码。

Git 只跟踪本说明文件。源材料的文件名、课次映射、字节数、SHA-256 和视频媒介元数据记录在 [`projects/algorithm-interview-course/inputs/source-catalog.json`](../../../projects/algorithm-interview-course/inputs/source-catalog.json)。在新环境中运行项目时，需要把获得授权的原始材料恢复到此目录，并确保哈希与目录记录一致。

原始材料需要单独备份；Git 忽略不等同于备份。
