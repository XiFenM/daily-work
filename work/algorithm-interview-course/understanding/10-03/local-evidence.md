## 证明义务核对

| 义务 | 画面是否满足 | 证据判断 |
| --- | --- | --- |
| 明确优化目标 | 是 | 最大化互不重叠区间数量。 |
| 明确贪心选择 | 是 | 在当前可选集合中取最早结束且与前一个已选区间不重叠者。 |
| 比较任一最优解 | 部分 | 引入最优值 `k` 与最优解当前选择 `j`，但“存在/任意最优解”的量词未正式写出。 |
| 构造交换 | 是 | 用贪心选择 `i` 替换最优解中的 `j`。 |
| 替换后仍可行 | 基本满足 | 明说“不影响后续的区间选择”；严格不等式 `f(i)<f(j)` 足以支持后继方向，但端点语义和已有前缀兼容性未形式化。 |
| 保持目标值 | 是 | 明说替换后仍构成大小为 `k` 的解。 |
| 并列结束时间 | 否 | 证明写 `f(j)>f(i)`，未处理 `f(j)=f(i)`；虽然同结束时间通常可同样交换，但这是外部补全，不是屏幕证据。 |
| 剩余子问题最优性 | 部分 | “不影响后续区间选择”表达了安全性，但未写出剩余实例、最优子结构等式或“后缀仍取最优”的独立引理。 |
| 对每一步重复交换/归纳 | 否 | “某次选择”暗示一般步骤，结尾也抽象为 `A` 替代 `O`，但没有显式归纳、循环交换、基例与终止步骤。 |
| 整体算法正确性结论 | 部分 | 屏幕直接宣布贪心选择性质成立；这足以支撑一阶交换引理，但从引理到整个迭代算法最优仍有未书写的证明桥梁。 |

## 完整性结论

**建议在正式笔记中将课程的证明标为 `partial`，并精确限定为：核心交换论证（greedy-choice lemma）基本完成，整个迭代算法的形式化正确性证明未完全闭合。**

理由：屏幕已经完成最关键的交换链条——选最早结束的 `i`，令某最优解当前选 `j`，以 `i` 替换 `j` 不损害后续可行选择，并保持解大小 `k`，从而与“最多 `k-1`”矛盾。这不是只有直觉的草图；对“存在一个包含当前贪心选择的最优解”这一贪心选择性质，证据相当充分。

但若把“complete”理解为对整个重复选择算法给出完整证明，画面仍缺少三处闭环：

1. 没有把“某次”正式量化为任意递归/迭代步骤，也没有给出归纳基例和终止。
2. “不影响后续选择”只陈述交换安全性，未单独证明剩余子问题仍须/仍能最优求解。
3. `f(j)=f(i)` 的并列结束时间未处理；区间端点相接的兼容定义也未写明。

因此最稳妥的证据标签是：

- 一步贪心选择/交换性质：`complete-with-minor-omissions`（或仓库若只允许二值，则可记为 `complete`，同时列出 tie/端点边界）。
- 整体贪心算法正确性：`partial`。
- 仅凭本地视觉证据无法确定讲师是否通过口述补全上述缺口；该点必须保留为不确定，不能反向推断为已讲或未讲。
