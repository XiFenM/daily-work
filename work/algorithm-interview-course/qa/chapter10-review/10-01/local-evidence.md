## 题面与示例

画面给出的模型：

- 每个孩子最多得到一块饼干。
- `g(i)` 是孩子 `i` 的“贪心指数”，即能让该孩子满足的饼干尺寸下限。
- `s(j)` 是饼干 `j` 的尺寸；当 `s(j) >= g(i)` 时可以满足孩子 `i`。
- 目标是在一对一分配约束下最大化满足的孩子数。

画面示例：

- `g=[1,2,3], s=[1,1]`，结果为 `1`。
- `g=[1,2], s=[1,2,3]`，结果为 `2`。

## 贪心方向与变量语义

屏幕实现不是常见的“升序、最小可用饼干满足最不贪心孩子”写法，而是其降序对偶：

1. `g` 和 `s` 都使用 `greater<int>()` 降序排序。
2. `gi` 指向当前最贪心的剩余孩子，`si` 指向当前最大的剩余饼干。
3. 若 `s[si] >= g[gi]`，当前最大饼干满足当前最贪心孩子：`res`、`si`、`gi` 都加一。
4. 否则只执行 `gi++`：连最大剩余饼干都无法满足当前孩子，跳过该孩子；保留该饼干尝试下一位更不贪心的孩子。
5. `res` 是已满足孩子数。循环在孩子或饼干任一侧耗尽时结束。

这组指针语义必须保持为上述方向；把失败分支写成 `si++` 会丢掉当前最大饼干并改变算法含义。

## 屏幕代码逐 token 复核

画面中可见的完整核心代码如下（保留原有类型、引用、比较器、分支和自增方向）：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
  int findContentChildren(vector<int>& g, vector<int>& s) {

    sort(g.begin(), g.end(), greater<int>());
    sort(s.begin(), s.end(), greater<int>());

    int si = 0, gi = 0;
    int res = 0;
    while( gi < g.size() && si < s.size() ){

      if( s[si] >= g[gi] ){
        res ++;
        si ++;
        gi ++;
      }
      else
        gi ++;
    }

    return res;
  }
};
```

代码事实与风险：

- 参数按非 const 引用接收，排序会原地改变两个输入数组。
- 屏幕只显式包含 `<iostream>`、`<vector>`、`<algorithm>`；本机 libc++ 可借由传递包含解析 `greater<int>`，但标准可移植写法应显式包含 `<functional>`。这是本地审阅结论，不应伪装成课程讲解。
- `gi`、`si` 是 `int`，而 `vector::size()` 是无符号 `size_type`，严格警告模式存在 signed/unsigned 比较问题。
