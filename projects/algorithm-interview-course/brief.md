# 算法面试课程归纳项目简报

## 目标

- 为课程中的每个课次建立一份详细、可复习、可追溯的中文笔记。
- 同时利用视频画面、讲解音频、屏幕代码和配套文本，保留课程真实的讲解顺序与论证过程。
- 建立跨课次知识关系，最终形成章节综述、题型索引、算法模板索引和课程知识地图。
- 明确区分“课程直接内容”“配套文本内容”“整理推导”和“补充说明”，不把模型常识伪装成课程原文。

## 当前输入

- 用户提供的课程目录：11 章、70 个课次。
- 已上传 70 个课程素材：67 个 MP4 视频和 3 个 Markdown 文本教程，覆盖全部 70 个课次，没有重复或缺课。
- 目录原有 66 个课次提供时长；第一至五章已改用 33 个视频的实测时长，因此当前已知课程时长至少为 18:30:09.344。
- `06-08`、`07-03`、`09-10` 是文本教程，没有视频时长。
- 第一至五章共 33 个视频已完成文件哈希、媒体探测、视频证据抽取、正式笔记和章节校准。

## 受众与语言

- 主要受众：正在系统准备算法面试、希望理解方法而不只记答案的学习者。
- 输出语言：简体中文；保留必要的英文术语、题名和复杂度记号。
- 输出形式：可版本控制的 Markdown/JSON 笔记与知识图谱，不涉及公开发布。

## 单课交付物

- 带时间戳的内容脉络。
- 学习目标、核心概念与定义。
- 题目、约束、澄清问题和解法演进。
- 算法模板或伪代码，以及正确性说明。
- 时间与空间复杂度及其成立条件。
- 示例推演、边界条件、测试用例和实现易错点。
- 面试表达脚本与可能的追问。
- 先修、延伸、对照、同类模式和后续应用关系。
- 复习清单、闪卡问题和证据/不确定项。

非题解型课次不强行套用题解结构；不适用的栏目要明确说明原因。

## 课程级交付物

- 每章综述与学习路径。
- 统一概念词表和同义词映射。
- 题型簇、数据结构、算法模板和易错点索引。
- 带来源、置信度和审核状态的跨课次关系图。
- 全课程复习路线和综合总结。

## 成功标准

- [ ] 所有上传素材均有哈希、媒介元数据和课次映射记录。
- [ ] 70 个课次均有明确状态；不存在静默漏课或重复计费处理。
- [ ] 每个有视频的课次都完成视频理解，并保留原始响应与 generation ID。
- [ ] 每份正式笔记的重要结论均能追溯到视频时间戳、文本段落或明确标注的整理推导。
- [ ] 代码片段注明来源；重建代码不得冒充屏幕原码。
- [ ] 复杂度结论包含适用条件，跨课关系包含证据和置信度。
- [ ] 每章完成术语、关系和内容一致性复核。
- [ ] 全课程完成后生成知识地图和复习索引。

## 安全、费用与版权边界

- 密钥只从根目录 `.env` 或当前进程环境变量读取，不写入项目文件。
- 原始课程素材放在被 Git 忽略的 `work/algorithm-interview-course/`，不提交到仓库。
- 模型原始响应放在被 Git 忽略的 `outputs/algorithm-interview-course/`。
- 正式笔记、Prompt、结构化元数据和关系图放在本项目目录中。
- 正式批处理前先用代表性课次校准 Prompt；失败重试必须记录原因，避免无审计重复调用。
- 不公开、上传或再分发课程原始素材。
