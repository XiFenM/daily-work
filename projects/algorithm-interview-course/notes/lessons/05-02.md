## `createLinkedList`：从数组构造链表

### 屏幕代码

```cpp
ListNode* createLinkedList(int arr[], int n) {
    if (n == 0)
        return NULL;
    ListNode* head = new ListNode(arr[0]);
    ListNode* curNode = head;
    for (int i = 1; i < n; i++) {

}
```

## `deleteLinkedList`：释放动态节点

### 屏幕代码

```cpp
void deleteLinkedList(ListNode* head) {
    ListNode* curNode = head;
    while (curNode != NULL) {
        ListNode* delNode = curNode;
        curNode = curNode->next;
        delete delNode;
    }
    return;
}
```

[visual_direct | ev-005 | 视频 07:44–09:58]

### 为什么先移动、后释放

每轮先保存：

```cpp
ListNode* delNode = curNode;
```

再执行：

```cpp
curNode = curNode->next;
```

此时 `curNode` 已经进入下一个仍存活的节点，`delNode` 指向本轮待释放节点。最后：

```cpp
delete delNode;
```

[course_direct + visual_direct | ev-005 | 视频 07:44–09:58]

如果先 `delete curNode`，再尝试读取 `curNode->next`，就会从已经释放的对象取后继地址；课程代码通过“先保存并推进，再释放”避免了这个顺序错误。[course_direct + editorial_inference | 基于 ev-005 | 视频 07:44–09:58]

### 删除不变量

进入每轮时：

> `curNode` 指向尚未释放链段的第一个节点；它之前的所有节点都已释放。

[editorial_inference | 基于 ev-005 | 视频 07:44–09:58]

本轮先保存当前对象，再让 `curNode` 进入后继，随后释放保存的对象，所以未释放链段减少一个节点，且下一轮不会依赖已释放节点读取 `next`。[editorial_inference | 基于 ev-005 | 视频 07:44–09:58]

若 `head == NULL`，循环零次，函数安全返回。[course_direct + editorial_inference | 基于 ev-005 | 视频 07:44–09:58]

## 正确性解释

本课没有围绕一个新算法提供形式化证明。规范化对象以 `experimental_validation` 记录课程样例；以下对三个辅助函数的说明是根据屏幕循环整理的局部不变量。[editorial_inference | 基于 ev-002–ev-005 | 视频 00:40–09:58]

### `createLinkedList`

- 初始化：`head` 和 `curNode` 指向由 `arr[0]` 创建的单节点链表；
- 保持：每轮把 `arr[i]` 创建成新尾节点并令 `curNode` 指向它；
- 终止：处理完 `i = n-1` 后，链表按数组顺序包含 `n` 个节点；
- 空输入：`n == 0` 时在访问 `arr[0]` 前返回 `NULL`。

[visual_direct + editorial_inference | 基于 ev-002 | 视频 00:40–03:20]

### `printLinkedList`

- 每轮打印当前可达节点一次；
- 随后沿 `next` 前进；
- 到 `NULL` 时停止并输出终止标记。

对有限无环链表，这会按当前连接顺序输出所有可达节点。[visual_direct + editorial_inference | 基于 ev-003 | 视频 03:20–05:16]

视频没有讨论有环链表；若输入存在环，当前打印循环不会按上述终止条件结束，因此不能把“所有链表”写成无条件保证。[补充说明]

### `deleteLinkedList`

- 每轮进入时 `curNode` 指向尚未释放的第一个节点；
- `delNode` 保存当前对象；
- `curNode` 在释放前推进到后继；
- `delete delNode` 只释放已经从后续遍历入口中移开的当前对象。

对有限无环链表，从正确头指针开始调用时，循环可逐个释放所有可达节点。[visual_direct + editorial_inference | 基于 ev-005 | 视频 07:44–09:58]

这些不变量是人工整理，不等于项目已运行，也不替代对内存异常路径的动态检查。[editorial_inference]
