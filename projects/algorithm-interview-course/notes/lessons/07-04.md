## 核心概念与定义

### 1. 递归函数契约

本课代码可以按下面的语义理解：

```text
hasPathSum(root, sum)
= 在以 root 为根的二叉树中，
  是否存在一条从 root 到该子树叶节点的路径，
  使路径节点和恰好等于当前剩余目标 sum
```

课程通过“把根节点值扣掉，再到左右子树寻找剩余和”表达了这一递归结构。[course_direct | ev-003, ev-004] 上面的完整契约措辞是为正确性解释整理的。[editorial_inference]

### 2. 根到叶路径

有效路径必须：

```text
从当前树的根节点开始
沿父子边向下
在叶节点结束
```

[course_direct + visual_direct | ev-002, ev-007]

经过一个值恰好使剩余和归零的**非叶节点**，仍不构成完整答案。[course_direct | ev-006, ev-007]

### 3. 叶节点

屏幕修正版使用：

```cpp
root->left == NULL && root->right == NULL
```

只有左右孩子同时为空，当前节点才是叶节点。[course_direct + visual_direct | ev-007, ev-008]

### 4. 空指针不是叶节点

`root == NULL` 描述的是“没有节点”。叶节点则是一个真实节点，只是它没有孩子。两者必须分开：

```text
root == NULL
    没有可用路径，返回 false

root 为叶节点
    比较 root->val 与剩余 sum
```

[course_direct + visual_direct | ev-007, ev-008]

### 第一步：递归分解

## 正确性解释

课程用反例说明错误并给出修正版，没有展示形式化证明。下面按递归契约整理。

### 1. 空树边界

若 `root == NULL`，当前子树没有任何从根到叶路径，返回 `false` 与契约一致。[course_direct + editorial_inference | 基于 ev-008]

### 2. 叶节点终止

若当前节点是叶节点，唯一可能的当前根到叶路径只包含它自身。因此：

```text
存在目标路径
⇔ root->val == sum
```

[course_direct + editorial_inference | 基于 ev-008]

### 3. 非叶节点递归保持

任何从当前根出发的根到叶路径，第一步必然进入左孩子或右孩子。扣除当前节点值后，剩余部分必须在对应子树中实现 `sum-root->val`。[editorial_inference | 基于 ev-003, code-003]

因此：

```text
hasPathSum(root, sum)
= hasPathSum(root->left, sum-root->val)
  OR
  hasPathSum(root->right, sum-root->val)
```

[course_direct + editorial_inference | 基于 ev-003, ev-009]

### 4. 可靠性与完备性

- 任一递归分支返回 `true`，都对应从某个孩子到其叶节点的合法路径；在前面加上当前根后，形成当前根到叶路径。
- 任一当前根到叶路径的第一条边必在左侧或右侧，所以两次递归不会遗漏合法路径。

[editorial_inference]

### 5. 终止性

每次递归都从当前节点进入一个孩子，沿有限树严格向下；最终到达空指针或叶节点，触发直接返回。[editorial_inference | 基于 code-003]

### 边界条件

1. **空树**：修正版返回 `false`。[visual_direct | ev-008]
