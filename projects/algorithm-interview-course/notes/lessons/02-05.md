## 核心概念与定义

### 1. 递归深度

递归深度是从第一次调用到终止条件所形成的最长调用链层数。[视频 00:00:45–00:03:21]

它由**每次调用如何改变问题规模**决定：

- 二分查找每次把搜索区间约减半，深度为 `log n`。[视频 00:00:45–00:03:21]
- `sum(n)` 每次变为 `sum(n-1)`，直到 `0`，深度为 `n` 量级。[视频 00:03:21–00:04:01]
- 快速幂每次把指数变为 `n/2`，深度为 `log n`。[视频 00:04:01–00:06:49]

这里的 `log n` 是渐进数量级表达；视频没有要求确定对数底数，且大 O 下常数底数不改变复杂度类别。[整理推导]

### 2. 单递归分支公式 `O(T × depth)`

课程给出的模型是：[视频 00:00:45–00:03:21]

```text
时间复杂度 = O(T × depth)
```

- `T`：每一层中除递归调用之外的操作成本。
- `depth`：递归调用链的深度。
- 前提：每次函数执行中只有一次继续向下的递归调用，且可用同一数量级 `T` 概括各层非递归工作。[视频 00:00:45–00:03:21]

更稳妥的理解是把每一层的成本相加；当每层都可由 `T` 上界时，和式才可压缩成 `T × depth`。[整理推导]

### 3. 递归树

递归树把一次函数调用画成一个节点，把它产生的递归调用画成子节点。总时间取决于：

1. 树有多少层；
2. 每层有多少节点；
3. 每个节点做多少非递归工作；
4. 所有层的工作量之和。[视频 00:06:49–00:13:52] [整理推导]

因此，“函数体里写了两次递归调用”只是描述分支数，还不足以给出结论。子问题规模是减 1 还是减半、每个节点是否还做线性合并，都会改变结果。[视频 00:06:49–00:13:52]

### 4. 主定理（Master Theorem）

课程只说明主定理能够归纳递归函数时间复杂度的一般情况，并表示普通面试通常不会在此处考查定理细节。[视频 00:13:52–00:14:46]

## 分析方法一：单次递归调用

### 递归二分查找

屏幕展示的代码为：[视频 00:00:45–00:03:21]

```cpp
int binarySearch(int arr[], int l, int r, int target) {
    if (l > r)
        return -1;

    int mid = l + (r - l) / 2;
    if (arr[mid] == target)
        return mid;
    else if (arr[mid] > target)
        return binarySearch(arr, l, mid - 1, target);
    else
        return binarySearch(arr, mid + 1, r, target);
}
```

推导：

1. 每次只进入左、右分支中的一个，属于单递归分支。[视频 00:00:45–00:03:21]
2. 每层只做中点计算、比较和返回等常数次操作，所以 `T = O(1)`。[视频 00:00:45–00:03:21]
3. 搜索范围每次减半，递归深度为 `O(log n)`。[视频 00:00:45–00:03:21]
4. 代入模型得 `O(1 × log n) = O(log n)`。[视频 00:00:45–00:03:21]

### 递归求和

```cpp
int sum(int n) {
    assert(n >= 0);

    if (n == 0)
        return 0;
    return n + sum(n - 1);
}
```

[视频 00:03:21–00:04:01]

每层只做常数次判断、加法与参数更新，`T = O(1)`；调用从 `n` 逐次减到 `0`，深度为 `O(n)`，所以总时间是 `O(n)`。[视频 00:03:21–00:04:01]

### 递归快速幂

```cpp
double pow(double x, int n) {
    assert(n >= 0);

    if (n == 0)
        return 1.0;

    double t = pow(x, n / 2);
    if (n % 2)
        return x * t * t;

    return t * t;
}
```

[视频 00:04:01–00:06:49]

这段代码的关键不是“出现了几个 `t`”，而是递归调用 `pow(x, n/2)` **只执行一次**，其结果被保存后复用。[视频 00:04:01–00:06:49]

- 每层把 `n` 除以 2，深度为 `O(log n)`。
- 每层只做常数次判断和乘法，非递归工作为 `O(1)`。
- 总时间为 `O(log n)`。[视频 00:04:01–00:06:49]

课程还提出 `n < 0` 时如何改写的思考题，但没有在本段证据中给出答案；本笔记不把某种负指数实现冒充为讲师结论。[视频 00:04:01–00:06:49]

## 分析方法二：多次递归调用

### 指数递归 `f(n-1) + f(n-1)`

```cpp
int f(int n) {
    assert(n >= 0);

    if (n == 0)
        return 1;

    return f(n - 1) + f(n - 1);
}
```

[视频 00:06:49–00:10:57]

递归树第 `0, 1, 2, …, n` 层的节点数分别为：

```text
2^0, 2^1, 2^2, …, 2^n
```

屏幕给出的求和公式是：[视频 00:06:49–00:10:57]

```text
2^0 + 2^1 + 2^2 + … + 2^n = 2^(n+1) - 1
```

每个节点的非递归工作为常数，因此总调用数决定总时间，得到 `O(2^n)`。[视频 00:06:49–00:10:57]

课程指出指数级算法非常慢，并提到可用剪枝或动态规划等方向优化；本课没有继续给出具体优化代码或复杂度。[视频 00:06:49–00:10:57]

### 归并排序：两个递归调用不等于指数级

```cpp
void mergeSort(int arr[], int l, int r) {
    if (l >= r)
        return;

    int mid = (l + r) / 2;
    mergeSort(arr, l, mid);
    mergeSort(arr, mid + 1, r);
    merge(arr, l, mid, r);
}
```

[视频 00:10:57–00:13:52]

以 8 个元素为例，视频画出的递归树各层子问题规模为：

```text
1 × 8
2 × 4
4 × 2
8 × 1
```

这里每层所有子问题的数据量之和都是 `n`；树深是 `log n`，每层的 `merge` 总工作量为 `O(n)`，所以总时间为 `O(n log n)`。[视频 00:10:57–00:13:52]

这一对照揭示了两棵递归树的本质差异：

- `f(n-1)+f(n-1)`：每条分支只减 1，树很深，节点数以指数方式增长。
- `mergeSort`：每条分支把规模减半；节点虽变多，但每层处理的数据总量仍为 `n`，层数只有 `log n`。[视频 00:06:49–00:13:52] [整理推导]

## 边界条件、易错点与测试

### 视频明确呈现的边界

- 二分查找以 `l > r` 表示区间为空并返回 `-1`。[视频 00:00:45–00:03:21]
- `sum`、快速幂和 `f` 都使用 `assert(n >= 0)`；基例是 `n == 0`。[视频 00:03:21–00:10:57]
- 快速幂必须区分奇偶指数；整数除法 `n/2` 会舍去余数，因此奇数分支需要额外乘一个 `x`。[视频 00:04:01–00:06:49]

### 常见误区

1. **看到递归就报 `O(n log n)`**：这是开场直接否定的判断方式。[视频 00:00:00–00:00:45]
2. **只数递归语句个数**：两个递归调用既可能产生 `O(2^n)`，也可能对应归并排序的 `O(n log n)`。[视频 00:06:49–00:13:52]
3. **快速幂重复计算同一个子问题**：课程代码先保存一次 `pow(x, n/2)` 的结果；若写成两次独立递归调用，递归树会发生变化，不能沿用本课的 `O(log n)` 推导。[视频 00:04:01–00:06:49] [整理推导]
4. **只看深度，不看每层总工作量**：归并排序每层还要处理合计 `n` 个元素。[视频 00:10:57–00:13:52]
5. **把时间结论自动当成空间结论**：视频没有在本课完成空间复杂度推导。[补充说明]
6. **把“提到主定理”当作“已讲完主定理”**：视频只做延伸提示。[视频 00:13:52–00:14:46]

## 复习区

### 核心清单

- 单递归分支：先求单层成本 `T`，再求深度 `depth`。[视频 00:00:45–00:06:49]
- 多递归分支：画递归树，统计节点数和每层工作量。[视频 00:06:49–00:13:52]
