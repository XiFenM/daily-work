## 核心概念与定义

### 1. 二叉树天然的递归结构

对任意非空二叉树：

- 左孩子所代表的结构仍是一棵二叉树；
- 右孩子所代表的结构仍是一棵二叉树；
- 空指针对应空树，构成递归定义的基本情况。

[course_direct + visual_direct | ev-002, ev-005 | 视频 01:17–02:25；05:39–05:58]

结构可以抽象为：

```text
Tree =
    Empty
    或 Node(value, left: Tree, right: Tree)
```

[editorial_inference | 基于 ev-002, ev-005]

这意味着，如果一个函数已经能处理“任意一棵更小的二叉树”，当前节点只需调用同一个函数处理左右子树，再组合结果。[course_direct + editorial_inference | 基于 ev-002, ev-003]

### 3. 递归终止条件

终止条件负责把递归问题落到一个可以立即回答的基本情况。本课二叉树代码的共同基本情况都是当前节点为空。[course_direct + visual_direct | ev-004, ev-005, ev-007, ev-008, ev-010]

对 `maxDepth`：

```cpp

    return 0;
```

空树没有节点，因此深度为 0。[course_direct | ev-010]

若递归函数没有可达的终止条件，调用会持续向系统栈压入信息，最终可能出现 Stack Overflow。[course_direct | ev-006 | 视频 05:58–07:05]

### 4. 递归过程

递归过程把当前问题交给更小的同类子问题，再组合其返回值。本课 `maxDepth` 的组合规则是：

```text
当前树最大深度
= max(左子树最大深度, 右子树最大深度) + 1
```

`+1` 代表当前根节点这一层。[course_direct + editorial_inference | 基于 ev-010]

```cpp
bool contain(Node* node, Key key) {
    if (node == NULL)

    if (key == node->key)

    if (contain(node->left, key) ||

        return true;

    return false;
}
```

## 递归契约与正确性解释

### 契约

> 对任意有限二叉树根指针 `root`，`maxDepth(root)` 返回以 `root` 为根的二叉树的最大深度；若 `root == NULL`，返回 0。

[course_direct + editorial_inference | 基于 ev-010]

### 基本情况

当 `root == NULL`：

```cpp
return 0;
```

空树深度为 0，契约成立。[course_direct + visual_direct | ev-010]

### 递归情况

假设递归调用满足契约：

- `maxDepth(root->left)` 正确返回左子树最大深度；
- `maxDepth(root->right)` 正确返回右子树最大深度。

任何从当前根到叶子的路径都先经过当前根，再完全进入左子树或右子树，因此最长路径应选择较深的子树并加上当前层：

```text
max(leftDepth, rightDepth) + 1
```

[course_direct + editorial_inference | 基于 ev-010]

### 终止性

每次递归都从当前节点进入其孩子；对有限、无环二叉树，路径最终到达 `NULL`，触发终止条件并逐层返回。[editorial_inference | 基于 ev-005, ev-010]

课程直接给出了递归关系和空树分支，但没有展开上述完整归纳证明；证明草图属于笔记整理。[course_direct + editorial_inference | ev-010]

[editorial_inference | 基于 ev-010]

### 3. 缺少终止条件

若不处理 `NULL`，代码会继续沿空孩子递归或解引用空指针；课程重点强调的是持续压栈最终导致 Stack Overflow。[course_direct | ev-006]

### 4. 忘记 `+1`

左右递归结果只表示子树深度；不加当前根这一层，会使非空树结果偏小。[editorial_inference | 基于 ev-010]

### 5. 把紧凑版误当成复杂度优化

两版代码访问同样的节点并形成同样的递归调用。内联局部变量只改变表达，不改变 Big O。[editorial_inference | 基于 code-001, code-002]

### 6. Minimum Depth 的机械替换陷阱

课程只给出警告：

```text
不能简单把 max 改成 min
```

[course_direct + visual_direct | ev-013 | 视频 15:15–16:01.24]

为什么值得警惕，可用一个只有单侧孩子的树作编辑性反例：

```text
root
  \
  child
```

若空子树仍返回 0，机械写成 `min(0, 1) + 1` 会得到 1；但根节点不是叶子，合法根到叶路径必须进入非空孩子。[editorial_inference | 基于 ev-013]

这只是解释陷阱，不是课程展示的完整 LeetCode 111 解法。本课没有给出它的分支处理代码、证明或复杂度。[补充说明]
