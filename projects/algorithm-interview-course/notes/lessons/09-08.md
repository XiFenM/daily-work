## 题目定义

给定整数序列，求最长严格上升子序列的长度。[course_direct + visual_direct | ev-001]

### 子序列不要求连续

从原序列删除任意若干元素，但保留剩余元素的相对顺序，即可得到子序列。例如：

```text
原序列：[10, 9, 2, 5, 3, 7, 101, 18]
子序列：[2, 5, 7, 101]
```

下标递增，但相邻被选元素在原数组中可以隔开。[course_direct | ev-001]

### 严格上升

合法相邻元素必须满足：

```text
previous < current
```

不能写成 `<=`。因此 `[7,7,7]` 的 LIS 长度是 1，而不是 3。[course_direct + editorial_inference | ev-001, ev-006]

### 求长度，不要求本课输出序列

多个最长上升子序列可能具有同一最大长度。LeetCode 300 本课目标是长度；具体序列重构会在 09-09 继续讨论。[course_direct + 跨课编辑连接 | ev-001]

## 暴力解法

每个元素都有“选/不选”两种选择，所以共有 `2^n` 个子序列；逐个检查是否严格上升需要最多 `O(n)`，总时间：

```text
O(2^n * n)
```

[course_direct + visual_direct | ev-002]

这个解法明确展示了指数级搜索空间，也是后续寻找重叠子问题的动机。

## 为什么状态要固定末尾

若只问：

```text
nums[0...i] 的 LIS 长度是多少？
```

很难判断 `nums[i+1]` 能否直接接到某个最优序列之后，因为最优序列的末尾值没有被状态保存。[editorial_inference]

课程改为：

```text
LIS(i) = 在 nums[0...i] 范围内，
         必须选择 nums[i] 作为结尾时的最长上升子序列长度
```

[course_direct + visual_direct | ev-003]

固定末尾后，是否能连接只需比较：

```text
nums[j] < nums[i]
```

而前半段的最好长度已经保存在 `LIS(j)` 中。

## 完整状态转移

课程画面原式：

```text
LIS(i) = max(1 + LIS(j) if nums[i] > nums[j])
         j < i
```

[course_direct + visual_direct | ev-003]

这张幻灯片没有把空候选集合的情况写出来。结合代码全 1 初始化，完整口径应写成：

```text
LIS(i) = max(
    1,
    max_{0 <= j < i, nums[j] < nums[i]} (LIS(j) + 1)
)
```

[course_direct + editorial_inference | ev-003, ev-006]

其中：

- `1`：只选择 `nums[i]` 本身；
- `LIS(j)+1`：把 `nums[i]` 接到一个以 `nums[j]` 结尾的最优序列之后；
- 对所有合法 `j` 取最大值：找到最好的前驱。[editorial_inference]

## 主示例手算

输入：

```text
[10, 9, 2, 5, 3, 7, 101, 18]
```

初始化所有位置为 1：

```text
nums: 10  9  2  5  3  7  101  18
memo:  1  1  1  1  1  1    1   1
```

逐步更新：[course_direct + visual_direct | ev-004]

- `10`：没有前驱，`1`；
- `9`：左侧没有更小值，`1`；
- `2`：左侧没有更小值，`1`；
- `5`：可接在 `2` 后，`2`；
- `3`：可接在 `2` 后，`2`；
- `7`：可接在长度 2 的 `5` 或 `3` 后，`3`；
- `101`：可接在长度 3 的 `7` 后，`4`；
- `18`：也可接在 `7` 后，`4`。

最终：

```text
memo = [1, 1, 1, 2, 2, 3, 4, 4]
answer = 4
```

[course_direct + visual_direct | ev-004]

合法答案示例包括 `[2,5,7,101]`、`[2,3,7,18]` 等；具体序列不唯一，长度一致。[course_direct + editorial_inference | ev-001, ev-004]

## 两个关键陷阱

### `memo` 不单调

课程反例：

```text
nums = [10, 15, 20, 11, 9, 101]
memo = [ 1,  2,  3,  2, 1,   4]
```

[course_direct + visual_direct | ev-005]

`memo[i]` 固定了不同的末尾值，所以它不表示前缀全局答案，完全可以下降。长度 3 的状态以 `20` 结尾，后面的 `11` 只能形成长度 2，并不矛盾。

### 不能找到第一个较小值就停止

即使某个靠近 `i` 的 `nums[j]` 小于 `nums[i]`，它的 `memo[j]` 也未必最大。必须检查全部 `j<i`，比较的是：

```text
所有合法前驱的 memo[j]
```

而不是：

```text
距离最近的较小元素
```

[course_direct + visual_direct | ev-005]

### 最终答案不是 `memo[n-1]`

最长上升子序列可能在最后一个数组元素之前结束。正确结果是：

```text
max(memo[0], memo[1], ..., memo[n-1])
```

[course_direct + visual_direct | ev-005, ev-006]

## 循环不变量

完成外层索引 `i` 后：

> 对每个 `0<=k<=i`，`memo[k]` 已等于所有以 `nums[k]` 结尾的严格上升子序列的最大长度。

[editorial_inference | 基于 ev-003, ev-004, ev-006]

初始化 `memo[k]=1` 让只选自身的情况成立。计算 `memo[i]` 时只读取 `j<i`，这些状态已经完成；枚举所有合法前驱后，不变量扩展到 `i`。[editorial_inference]

## 正确性骨架

任意以 `nums[i]` 结尾、长度大于 1 的严格上升子序列，都有一个倒数第二个元素 `nums[j]`，且：

```text
j < i
nums[j] < nums[i]
```

删除最后的 `nums[i]` 后，剩余部分是一个以 `nums[j]` 结尾的上升子序列，长度不超过 `LIS(j)`；因此候选不超过 `LIS(j)+1`。[editorial_inference]

反过来，对任一满足条件的 `j`，把 `nums[i]` 接到一条长度为 `LIS(j)` 的序列后仍严格上升，所以 `LIS(j)+1` 可实现。对全部 `j` 取最大即得到精确状态值。[editorial_inference]

最后，任何全局 LIS 都有某个末尾下标 `i`，所以全局答案为 `max_i LIS(i)`。[course_direct + editorial_inference | ev-005, ev-006]

## 视频核心代码

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        if( nums.size() == 0 )
            return 0;

        // memo[i] 表示以 nums[i] 为结尾的最长上升子序列的长度
        vector<int> memo(nums.size(), 1);
        for( int i = 1 ; i < nums.size() ; i ++ )
            for( int j = 0 ; j < i ; j ++ )
                if( nums[j] < nums[i] )
                    memo[i] = max( memo[i] , 1 + memo[j] );

        int res = 1;
        for( int i = 0 ; i < nums.size() ; i ++ )
            res = max( res , memo[i] );

        return res;
    }
};
```

## 面试回答模板

1. **澄清定义**：子序列可不连续，要求严格上升；
2. **定义状态**：`dp[i]` 是以 `nums[i]` 结尾的最长长度；
3. **初始化**：每个元素单独成序列，全部为 1；空数组单独返回 0；

7. **复杂度**：`O(n^2)` 时间、`O(n)` 辅助空间；
