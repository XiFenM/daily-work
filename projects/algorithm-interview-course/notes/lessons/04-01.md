```cpp
using namespace std;

class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {

        set<int> record;
        for (int i = 0; i < nums1.size(); i++)
            record.insert(nums1[i]);

        for (int i = 0; i < nums2.size(); i++)
            if (record.find(nums2[i]) != record.end())

    }
};
```

- `n = nums1.size()`；
- `m = nums2.size()`；
- `u` 为 `nums1` 中不同元素数量；
- `k` 为最终不同交集元素数量。

按 `std::set` 的对数级查找、插入复杂度契约保守估算：

1. 构造 `record` 处理 `n` 个输入，时间为 `O(n log n)`；
2. 扫描 `nums2` 做 `m` 次成员查找，并在命中时向 `resultSet` 插入，保守写作 `O(m log n)`；
3. 将 `k` 个结果元素复制到向量，时间为 `O(k)`。

因此可用较易表达的上界：


## 边界条件、易错点与建议测试

### 课程证据直接支持的注意点

1. **输出必须去重**：不能把 `nums2` 中每次命中都直接无条件追加到向量，否则示例中的两个 `2` 会产生重复结果。[course_direct + visual_direct | ev-003, ev-004 | 视频 03:48–09:18]
2. **不能依赖输出顺序**：题目明确允许任意顺序，测试不应锁定当前 `std::set` 迭代顺序。[course_direct + visual_direct | ev-003 | 视频 03:48–05:22]
3. **成员判断要与 `end()` 比较**：屏幕代码使用 `find(x) != record.end()` 表示查找成功。[visual_direct | ev-004, ev-005 | 视频 05:22–11:15.283]
4. **`record` 和 `resultSet` 职责不同**：前者记录 `nums1` 的成员，后者记录已经确认的唯一交集。[visual_direct + editorial_inference | 基于 ev-004 | 视频 05:22–09:18]
5. **区间构造的尾端是 `end()`**：不要解引用或错误地把尾后迭代器当作有效元素。[visual_direct + editorial_inference | 基于 ev-005 | 视频 09:18–11:15.283]

### 常见错误

- 只使用 `record` 查找，却把每个命中直接 `push_back` 到向量，导致 `nums2` 的重复值重复输出。[editorial_inference | 基于 ev-003, ev-004 | 视频 03:48–09:18]
- 把条件写成 `record.find(x) == record.end()` 后仍当作命中处理，逻辑反转。[editorial_inference | 基于 ev-004 | 视频 05:22–09:18]
- 误以为 `set` 会保存重复次数；它只表达成员有无，若题目要求按出现次数求交集，需要 `map` 或其他频次结构。[editorial_inference | 基于 ev-001, ev-003 | 视频 00:00–01:51；03:48–05:22]
- 把当前实现产生的有序向量当成题目保证，令代码或测试依赖不必要的次序。[editorial_inference | 基于 ev-003, ev-005 | 视频 03:48–05:22；09:18–11:15.283]
- 写区间构造时混用不同容器的 `begin()` 和 `end()`，形成无效迭代器范围。[editorial_inference | 基于 ev-005 | 视频 09:18–11:15.283]
