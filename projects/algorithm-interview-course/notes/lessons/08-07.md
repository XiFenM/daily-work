## 题目与约束

课程题面把地图表示为二维字符数组：

- `'1'` 代表陆地；
- `'0'` 代表水域；
- 横向或纵向相邻的陆地属于同一岛屿；
- 水域将不同岛屿分隔开；
- 问地图中共有多少个岛屿。[course_direct + visual_direct | ev-002 | 视频 00:50–02:15]

这里有两个容易被代码字体掩盖的细节。

### 字符 `'1'`，不是整数 `1`

代码条件是：

```cpp
grid[i][j] == '1'
```

单引号表示字符。写成 `grid[i][j] == 1` 比较的是字符编码与整数值 `1`，不是题面中的陆地字符。[visual_direct | ev-006, ev-007] [editorial_inference | 类型语义说明]

### 四邻域，不是八邻域

课程方向数组只包含：

```text
(0, 1), (1, 0), (0, -1), (-1, 0)
```

分别对应右、下、左、上。对角线方向没有进入数组，因此两个只在角上接触的 `'1'` 仍属于两个岛屿。[course_direct + visual_direct | ev-002, ev-005]

## 从动画理解 flood fill

课程先把陆地画成棕色，把已经访问的格子画成红色。从某个陆地起点开始，红色沿相邻陆地扩散，直至整个四连通区域都被覆盖。[course_direct + visual_direct | ev-003 | 视频 02:15–06:18]

这可以拆成两个层次。

### 层次一：发现新的连通块

外层双循环按行扫描所有位置：

```text
如果当前位置是陆地，并且此前没有访问过：
    res += 1
    从当前位置 flood fill
```

计数发生在 flood fill **之前**。它表示“发现了一个此前没有归属记录的新岛屿入口”。[course_direct + visual_direct | ev-004, ev-006]

### 层次二：吞掉整个连通块

从入口出发的 DFS 不再增加 `res`；它只负责把与入口四连通的所有陆地标成 `visited=true`。这样外层扫描以后碰到同一岛屿的其他格子时，不会重复计数。[course_direct + visual_direct | ev-003, ev-004, ev-007, ev-008]

## 状态模型

### `m` 与 `n`

- `m = grid.size()`：行数；
- `n = grid[0].size()`：列数；
- `inArea(x, y)` 统一检查 `0 <= x < m` 且 `0 <= y < n`。[course_direct + visual_direct | ev-005, ev-006]

### `visited`

`visited[x][y] == true` 的准确含义是：

> 该格已经被某次 flood fill 纳入一个已发现的连通块，后续所有扫描与递归都不应再次把它当成新状态处理。[course_direct + editorial_inference | 基于 ev-006–ev-008]

初始化为：

```cpp
visited = vector<vector<bool>>(m, vector<bool>(n, false));
```

它在一次 `numIslands` 调用内覆盖整张地图，而不是每次 DFS 重新创建。[course_direct + visual_direct | ev-006]

### `res`

`res` 不是已访问陆地格子的数量，而是已经发现的岛屿入口数量。只有外层扫描遇到：

```cpp
grid[i][j] == '1' && !visited[i][j]
```

时才加一。[course_direct + visual_direct | ev-006]

## 为什么这里不回溯 `visited`

上一课 Word Search 中，`visited` 表示“当前候选单词路径已经使用的格子”。某条路径失败后，兄弟路径仍有权使用该格，因此要恢复为 `false`。[course_direct | 08-06 ev-008]

本课不同：

- 一旦某个陆地格被访问，就已经确定它属于当前岛屿；
- 这个归属不会因某个递归分支返回而失效；
- 后续分支和外层扫描都应该知道它已经被处理；
- 恢复为 `false` 反而会导致重复访问，严重时还可能在无环保护缺失时来回递归。[course_direct | ev-008] [editorial_inference | 后果分析]

所以，是否恢复状态不取决于“用了递归还是回溯”，而取决于状态的语义：

| 问题              | `visited` 的语义        | 返回时是否恢复 |
| ----------------- | ----------------------- | -------------- |
| Word Search       | 当前候选路径占用        | 失败后恢复     |
| Number of Islands | 全局连通块归属/永久去重 | 不恢复         |

## 递归契约与终止

可以把课程代码整理成以下契约：

> 调用 `dfs(grid, x, y)` 前，保证 `(x,y)` 在地图内、尚未访问且 `grid[x][y]=='1'`；函数返回时，从该起点通过上下左右陆地可达的所有格子都已永久标记为访问。[course_direct + editorial_inference | 基于 ev-007, ev-008 与 code-001]

### 为什么没有开头的显式基本情况

`dfs` 自身一进入就标记当前格，然后枚举四个邻居。它只在以下条件全部成立时继续递归：

```cpp
inArea(newx, newy)
&& !visited[newx][newy]
&& grid[newx][newy] == '1'
```

当四个方向都越界、是水、或已经访问时，不会产生新的递归调用，循环自然结束并 `return`。终止条件被放到了“调用下一层之前”，而不是写成被调函数开头的单独分支。[course_direct + visual_direct | ev-007, ev-008]

### 为什么递归一定终止

每次进入一个陆地格就永久把 `visited` 设为 `true`，而递归只进入未访问格。有限地图中的格子数量有限，因此不可能无限产生新的递归层。[editorial_inference | 基于 code-001]

## 课程核心 `Solution` 与本地编译外壳

屏幕中的 `#include` 区域被 IDE 折叠为 `#include ...`；以下显式 `<vector>` 是本地语法检查所需的最小编译外壳，`Solution` 内容与规范化视频代码工件一致。[补充说明 | code-001]

```cpp
#include <vector>

using namespace std;

class Solution {
private:
    int d[4][2] = {{0,1}, {1,0}, {0,-1}, {-1,0}};
    int m, n;
    vector<vector<bool>> visited;

    bool inArea(int x, int y) {
        return x >= 0 && x < m && y >= 0 && y < n;
    }

    // 从grid[x][y]的位置开始，进行floodfill
    // 保证(x,y)合法，且grid[x][y]是没有被访问过的陆地
    void dfs(vector<vector<char>>& grid, int x, int y) {
        visited[x][y] = true;

        for (int i = 0; i < 4; i++) {
            int newx = x + d[i][0];
            int newy = y + d[i][1];
            if (inArea(newx, newy)
                && !visited[newx][newy]
                && grid[newx][newy] == '1')
                dfs(grid, newx, newy);
        }
        return;
    }

public:
    int numIslands(vector<vector<char>>& grid) {
        m = grid.size();
        if (m == 0)
            return 0;
        n = grid[0].size();

        visited = vector<vector<bool>>(m, vector<bool>(n, false));

        int res = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == '1' && !visited[i][j]) {
                    res++;
                    dfs(grid, i, j);
                }

        return res;
    }
};
```

## 正确性说明

以下完整证明是对课程动画与代码的编辑整理。

### 单次 DFS 的可靠性

从合法、未访问陆地起点 `(x,y)` 调用：

1. 当前格立即被标记，因此不会再次从邻居回到这里；
2. 每次递归只进入界内、未访问且为 `'1'` 的四邻格，所以不会越界、跨过水域或重复访问；
3. 对每个满足条件的相邻陆地都会递归，因此所有从起点四连通可达的陆地最终都会被访问；
4. 递归不使用斜向偏移，所以不会把仅对角接触的另一块陆地错误合并。[editorial_inference | 基于 ev-002、ev-005–ev-008]

因此，`dfs` 返回后恰好标记了起点所属岛屿的全部陆地。[editorial_inference]

### 外层计数不重不漏

- **不漏**：若某个岛屿此前未被统计，扫描到该岛屿最早出现的格子时，它一定是 `'1'` 且未访问，于是触发一次计数与 DFS。
- **不重**：首次触发的 DFS 会标记该岛屿所有格子；扫描到同岛其他格子时，`visited` 已为 `true`，不会再次计数。
- **不混**：DFS 不会穿过水域，也不会走斜线，因此不同四连通分量不会被同一次搜索合并。[editorial_inference | 基于 ev-003、ev-004、ev-006、ev-007]

所以最终 `res` 等于岛屿数量。

## 复杂度

设网格有 `m` 行、`n` 列。

- 外层扫描检查 `mn` 个格子；
- 每个陆地格最多第一次被 DFS 进入一次；
- 每次进入只检查四个方向；
- 因此时间复杂度为 `O(mn)`；
- `visited` 矩阵占 `O(mn)`；
- 最坏情况下整张地图都是一条很深的连通路径，递归栈可达 `O(mn)`；
- 不计输入与调用栈之外，辅助空间整体为 `O(mn)`。[editorial_inference | 基于 code-001]

课程没有直接分析这些复杂度。尤其不能因为每格检查四个方向就写成 `O(4mn)` 之外的不同渐进阶；常数 4 在 Big O 中被省略。

## 边界条件

### 空网格

当 `m == 0` 时直接返回 `0`，并且不会访问 `grid[0]`。[course_direct + visual_direct | ev-006]

### 零列网格

若 `grid` 有行但首行长度为 0，则 `n == 0`，访问矩阵具有 0 列，双循环内层不执行，结果仍为 0。[editorial_inference | 基于 code-001；课程未单独讨论]

### 全是水

没有格子满足 `'1' && !visited`，返回 0。[editorial_inference]

### 全是陆地

第一次陆地触发一次 DFS，整张四连通地图被标记，最终返回 1。[editorial_inference]

### 只在对角线相邻

每个对角线上的 `'1'` 都是独立岛屿，因为方向数组不含斜向偏移。[course_direct + editorial_inference | ev-002, ev-005]

### 非矩形网格

实现统一使用 `n = grid[0].size()` 检查所有行，按矩形二维数组设计；课程没有定义不等长行输入。[editorial_inference | 基于 code-001]

## 手工跟踪

考虑：

```text

0 1 0
```

1. 扫描 `(0,0)`：是未访问陆地，`res=1`；
2. DFS 标记 `(0,0)`、`(0,1)`、`(1,1)`；

6. 两个底部陆地只在斜向或隔水位置上相对，不合并。[editorial_inference | 用课程四邻域规则推演]

## 常见错误

1. **把 `'1'` 写成 `1`**：字符与整数值不是同一比较。[visual_direct + editorial_inference | ev-006, ev-007]
2. **加入四个斜向方向**：会改变题目的连通定义。[course_direct | ev-002]
3. **忘记 `visited`**：相邻陆地可能沿无向边反复进入，导致重复搜索甚至无限递归。[editorial_inference]
4. **像 Word Search 一样恢复 `visited`**：会破坏全局连通块去重语义。[course_direct | ev-008]
5. **每次 DFS 都重新创建访问矩阵**：同一岛屿会被外层多次统计。[editorial_inference | 基于 code-001]
6. **先访问 `grid[newx][newy]` 再检查边界**：越界坐标会触发非法访问；课程条件利用 `&&` 短路先执行 `inArea`。[visual_direct + editorial_inference | ev-007]

## 闪卡

1. **问**：什么时候把 `res` 加一？ **答**：外层扫描遇到字符 `'1'` 且尚未访问时。
2. **问**：一次 DFS 的职责是什么？ **答**：永久标记起点所属的整个四连通陆地分量。
3. **问**：为什么不需要显式 `if (...) return` 基本情况？ **答**：不合法、已访问或非陆地邻居不会触发下一次递归，循环结束后自然返回。
4. **问**：本题为什么不能恢复 `visited`？ **答**：它记录全局连通块归属，后续扫描必须保留去重信息。
5. **问**：Word Search 为什么相反？ **答**：它的标记只表示当前候选路径占用，失败后兄弟路径仍可使用该格。
6. **问**：对角线相邻是否同岛？ **答**：否，课程只定义上下左右连接。
7. **问**：时间复杂度为什么是 `O(mn)`？ **答**：外层扫描所有格，每格最多首次被 DFS 进入一次，每次只检查四个方向；这是编辑推导。
8. **问**：130 与 417 在本课是什么状态？ **答**：只列出的思考题，没有完整方案。
