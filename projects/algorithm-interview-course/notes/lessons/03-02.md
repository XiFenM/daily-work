## 核心概念与定义

### 1. 左闭右开候选区间 `[l, r)`

本课把搜索状态定义成：

> 如果 `target` 存在且尚未返回，那么它一定在当前区间 `[l, r)` 中。

左端点 `l` 属于区间，右端点 `r` 不属于区间。因此 `[l, r)` 实际包含的索引是 `l, l+1, …, r-1`。[视频 00:00:00–00:03:53]

由定义可立即得到两个边界事实：

- `[42, 43)` 包含索引 `42`，是单元素区间；
- `[42, 42)` 不包含任何索引，是空区间。

[视频 00:01:00–00:03:53]

这也是为什么 `l == r` 时不应再进入循环：对于半开区间，它表示候选集合已经为空，而不是“还剩最后一个元素”。[视频 00:01:00–00:03:53]

### 2. 循环不变量

循环不变量不是“变量的值不变”，而是变量所表达的逻辑关系在每轮都成立。本课的关系是：所有尚未排除的目标位置都落在 `[l, r)` 内。[视频 00:01:00–00:03:53] [视频 00:08:19–00:12:06]

每个分支更新都要回答同一个问题：

1. 哪些索引已经由比较结果排除？
2. 新的 `[l, r)` 是否仍覆盖全部可能位置？
3. 新区间是否严格缩小，从而保证循环最终结束？

[视频 00:01:00–00:03:53] [整理推导]

### 3. 整型溢出

若 `l` 和 `r` 都接近整数类型上限，数学上的 `l + r` 可能超过该类型的可表示范围；即使最后再除以 2，中间加法也已经发生溢出。[视频 00:06:02–00:08:19]

课程给出的替代表达式是：

```cpp
int mid = l + (r - l) / 2;
```

在本课维持 `0 <= l <= r` 的前提下，`r - l` 表示区间长度，不需要先计算两个大正数的和，因此避免了原式的加法溢出风险。[视频 00:06:02–00:08:19] [整理推导]

## 两套区间约定：分别成立，不能混写

下表把 03-01 的闭区间版本与本课半开区间版本并列。闭区间细节来自 03-01；半开区间细节来自本课。比较的目的不是选出“唯一正确模板”，而是看清每个符号如何由定义决定。[视频 03-01 00:05:00–00:13:40] [视频 00:00:00–00:03:53]

| 决策点     | 闭区间 `[l, r]`    | 左闭右开 `[l, r)`        | 为什么不同                          |
| ---------- | ------------------ | ------------------------ | ----------------------------------- |
| 区间含义   | `l`、`r` 都是候选  | `l` 是候选，`r` 不是候选 | 右端点的包含关系不同                |
| 初始状态   | `l = 0, r = n - 1` | `l = 0, r = n`           | `[0,n-1]` 与 `[0,n)` 都覆盖 `0…n-1` |
| 非空条件   | `l <= r`           | `l < r`                  | `[x,x]` 含一个元素，而 `[x,x)` 为空 |
| 目标更大   | `l = mid + 1`      | `l = mid + 1`            | 两种约定都必须排除已检查的 `mid`    |
| 目标更小   | `r = mid - 1`      | `r = mid`                | 半开区间的右端点本来就不包含 `mid`  |
| 空区间状态 | `l > r`            | `l == r`                 | 由各自的非空定义直接得到            |

两套代码可以各自正确，但以下“拼装版本”没有一致的区间语义：

- `r = n` 却把候选区间当 `[l, r]`，会把数组之外的索引 `n` 误当成候选；
- `[l, r)` 却使用 `while (l <= r)`，在空区间 `l == r` 时仍会进入循环；
- `[l, r)` 中目标更小时写 `r = mid - 1`，会额外排除本应仍在候选中的 `mid - 1`；
- `[l, r]` 中目标更小时写 `r = mid`，又可能把已经比较失败的 `mid` 留在候选集合里。

## 半开区间版本的构造

### 第一步：用 `[0, n)` 覆盖全部合法索引

长度为 `n` 的数组合法索引是 `0…n-1`。由于右端点不包含在半开区间中，覆盖全部元素的初始候选集合正好是：

```cpp
int l = 0, r = n;
```

[视频 00:00:00–00:01:00]

当 `n == 0` 时，初始区间是 `[0,0)`，天然为空；这与空数组没有候选元素相符。[视频 00:01:00–00:03:53] [整理推导]

### 第二步：由非空定义推出 `l < r`

半开区间只有在左端点严格小于右端点时才至少包含一个元素，因此：

```cpp
while (l < r)
```

[视频 00:01:00–00:03:53]

这里不能写闭区间版本的 `l <= r`。当 `l == r` 时 `[l,r)` 已为空，继续计算并访问 `arr[mid]` 没有候选语义支撑。[视频 00:01:00–00:03:53]

### 第三步：比较中点并严格排除 `mid`

若 `arr[mid] == target`，直接返回 `mid`。未命中时：

- `target > arr[mid]`：`mid` 及其左侧不可能命中，保留 `[mid + 1, r)`，所以 `l = mid + 1`；
- `target < arr[mid]`：`mid` 及其右侧不可能命中，保留 `[l, mid)`，所以 `r = mid`。

[视频 00:01:00–00:03:53]

`r = mid` 并没有继续包含 `mid`，因为右端点在 `[l, r)` 中本来就是排除的。把这一点说清楚，比背诵“半开版本不减一”更可靠。[视频 00:01:00–00:05:23]

### 第四步：空区间表示未找到

循环退出时 `l == r`，候选集合 `[l,r)` 为空；若此前没有命中，就返回 `-1`。[视频 00:01:00–00:03:53]

## 视频中的完整实现

```cpp
template<typename T>
int binarySearch(T arr[], int n, T target) {

    int l = 0, r = n; // 在 [l...r) 的范围里寻找 target
    while (l < r) {   // 当 l == r 时，区间 [l...r) 是无效的
        int mid = l + (r - l) / 2;
        if (arr[mid] == target)
            return mid;
        if (target > arr[mid])
            l = mid + 1; // target 在 [mid+1...r) 中
        else             // target < arr[mid]
            r = mid;     // target 在 [l...mid) 中
    }

    return -1;
}
```

## 正确程序的四步方法

课程在结尾给出四项总结。这四项不是互相替代，而是分别处理“设计是否一致”和“实现是否经受检查”。[视频 00:08:19–00:12:06] [整理推导]

小样例适合定位边界，大样例适合暴露性能、长循环和少见状态问题。测试应作为证明之外的实现检查层，而不是替代不变量推理。[视频 00:05:23–00:06:02] [视频 00:08:19–00:12:06] [整理推导]

## 边界条件、易错点与建议测试

### 视频直接强调的错误

1. **把 `[l,r)` 写成 `l <= r`**：`l == r` 时区间已经为空，继续循环破坏定义。[视频 00:01:00–00:03:53]
2. **目标更小时仍写 `r = mid - 1`**：这是闭区间规则；半开区间的新右端点应是 `mid`。[视频 00:01:00–00:03:53]
3. **孤立背诵符号**：不理解变量语义时，很容易把两种合法模板拼成一个不合法实现。[视频 00:03:53–00:05:23]
4. **使用 `(l + r) / 2`**：大边界下中间加法可能溢出，应改用 `l + (r - l) / 2`。[视频 00:06:02–00:08:19]

## 复习区

### 核心清单

- `[l,r)` 包含 `l…r-1`，不包含 `r`。[视频 00:00:00–00:03:53]
- 初始右边界为 `r=n`，不是 `n-1`。[视频 00:00:00–00:01:00]
- `l==r` 时区间为空，所以循环条件是 `l<r`。[视频 00:01:00–00:03:53]
- 目标更大时 `l=mid+1`；目标更小时 `r=mid`。[视频 00:01:00–00:03:53]
- 闭区间 `[l,r]` 与半开区间 `[l,r)` 都能正确，但规则不能交叉拼装。[视频 00:00:00–00:05:23]
- 中点使用 `l+(r-l)/2` 可避免先计算 `l+r` 的溢出风险。[视频 00:06:02–00:08:19]
- 正确程序的四步方法是：变量含义、循环不变量、小数据调试、大数据测试。[视频 00:08:19–00:12:06]
- 百万规模断言是经验测试，不是普遍正确性的形式化证明。[视频 00:05:23–00:06:02] [整理推导]
