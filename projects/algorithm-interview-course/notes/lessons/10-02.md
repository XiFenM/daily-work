## 题目定义与端点语义

给定若干区间，删除尽可能少的区间，使剩余区间两两不重叠。[course_direct + visual_direct | ev-002]

课程给出两个前提：

```text
每个区间满足 start < end
[1,2] 与 [2,3] 不算重叠
```

[course_direct + visual_direct | ev-002]

第二条决定兼容条件必须允许相等：

```text
current.start >= previous.end
```

若错误写成 `>`，就会把本题明确允许的端点相接误判为冲突。

### 课程示例

```text
[[1,2], [2,3], [3,4], [1,3]] -> 1
```

删除 `[1,3]` 后可保留前三个首尾相接的区间。

```text
[[1,2], [1,2], [1,2]] -> 2
```

三个完全相同的区间最多保留一个。[course_direct + visual_direct | ev-002]

### 澄清边界

本题已经直接给出 `start<end`，因此不能凭空增加“先纠正反向区间”这一课程未提出的处理步骤。迁移到其他区间问题时，可以向面试官确认端点相接是否算冲突；对本题则应遵守已给定语义。[course_direct + editorial calibration | ev-002]

## 从最少删除到最多保留

设区间总数为 `n`，最多能保留 `k` 个互不重叠区间，则最少删除数必然是：

```text
n - k
```

[course_direct + visual_direct | ev-003]

这一步很重要，因为“删除哪些”看似是破坏冲突，而“保留哪些”变成了寻找最大兼容集合，更容易和 LIS、区间调度联系起来。

## 基线：枚举所有子集

每个区间都有“保留/删除”两种选择，因此共有 `2^n` 个子集；对每个子集最多再用 `O(n)` 判断是否互不重叠：

```text
O(2^n * n)
```

[course_direct + visual_direct | ev-003]

这是本课画面直接给出的复杂度。指数级搜索说明必须利用排序和子问题结构。

## 方案一：动态规划

### 为什么先按起点排序

DP 比较器为：

```cpp
bool compare(const Interval &a, const Interval &b) {
    if (a.start != b.start)
        return a.start < b.start;
    return a.end < b.end;
}
```

[course_direct + visual_direct | code-001, ev-005]

排序后，所有可能成为 `i` 前驱的候选都位于更小下标。相同起点时再按终点升序，使顺序确定；真正能否连接仍由 `previous.end <= current.start` 判断。

### 屏幕注释与真实状态的差异

屏幕代码注释写作：

```cpp
// memo[i]表示使用intervals[0...i]的区间能构成的最长不重叠区间序列
```

[visual_direct | code-001, ev-005]

这句话若理解成“前缀 `0...i` 的无条件最优值”，就和代码不一致：代码没有用 `memo[i-1]` 更新 `memo[i]`。

实际精确定义必须是：

```text
memo[i] = 在排序后的 intervals[0...i] 中，
          必须选择 intervals[i] 作为最后一个区间时，
          能得到的最长不重叠区间序列长度
```

[editorial_inference | 基于 ev-005]

这与第九章 LIS 的“固定末端”状态完全同构：固定末端后，才能通过比较前驱终点判断能否连接。

### 初始化

```cpp
vector<int> memo(intervals.size(), 1);
```

每个区间单独保留时，都构成长为 1 的合法序列。[course_direct + visual_direct | ev-005]

### 状态转移

对每个 `i` 枚举全部 `j<i`：

```cpp
if (intervals[i].start >= intervals[j].end)
    memo[i] = max(memo[i], 1 + memo[j]);
```

[course_direct + visual_direct | ev-005]

完整公式是：

```text
memo[i] = max(
    1,
    max_{0 <= j < i, intervals[j].end <= intervals[i].start}
        (memo[j] + 1)
)
```

[course_direct + editorial_inference | ev-005]

其中 `>=` 正好编码端点相接不算重叠。

### 为什么答案不是 `memo[n-1]`

因为状态固定了末端，最后一个排序区间未必属于全局最优兼容集合。因此需要：

```cpp
int res = 0;
for (int i = 0; i < memo.size(); i++)
    res = max(res, memo[i]);

return intervals.size() - res;
```

[course_direct + visual_direct | ev-005]

`res` 是最多保留数，最终返回 `n-res`。

### DP 正确性骨架

对固定 `i`：

1. 任意以 `i` 结尾、长度大于 1 的合法序列都有某个倒数第二个区间 `j<i`；
2. 它必须满足 `intervals[j].end <= intervals[i].start`；
3. 删除末尾 `i` 后，前半段长度不超过 `memo[j]`；
4. 枚举所有合法 `j` 并取最大，覆盖所有以 `i` 结尾的候选；
5. 再对所有末端 `i` 取最大，覆盖全局最优解。[editorial_inference | 基于 ev-005]

### DP 屏幕核心代码

以下保留屏幕状态注释原貌；注释与实际状态的语义差异已在上文单独校准，没有静默改写课程画面：

```cpp
bool compare(const Interval &a, const Interval &b) {
    if (a.start != b.start)
        return a.start < b.start;
    return a.end < b.end;
}

class Solution {
public:
    int eraseOverlapIntervals(vector<Interval>& intervals) {
        if (intervals.size() == 0)
            return 0;

        sort(intervals.begin(), intervals.end(), compare);

        // memo[i]表示使用intervals[0...i]的区间能构成的最长不重叠区间序列
        vector<int> memo(intervals.size(), 1);
        for (int i = 1; i < intervals.size(); i++) {
            for (int j = 0; j < i; j++) {
                if (intervals[i].start >= intervals[j].end) {
                    memo[i] = max(memo[i], 1 + memo[j]);
                }
            }
        }

        int res = 0;
        for (int i = 0; i < memo.size(); i++) {
            res = max(res, memo[i]);
        }

        return intervals.size() - res;
    }
};
```

[course_direct + visual_direct | code-001, ev-005]

### DP 复杂度

- 排序：`O(n log n)`；
- 双重前驱枚举：`O(n^2)`；
- 最后扫描 `memo`：`O(n)`；
- 总时间：`O(n^2)`，课程直接口述确认；
- `memo` 长度为 `n`，辅助空间 `O(n)`，这是根据代码分配作出的编辑推导。[course_direct + editorial_inference | ev-005, ev-006]

## 方案二：结束时间最早的贪心

### 贪心观察

课程强调：每次选择中，区间的**结尾**很重要。一个可选区间结束得越早，就越少占用后面的时间轴，后续越可能容纳更多区间。[course_direct + visual_direct | ev-007]

因此策略是：

```text
按 end 从小到大排序；
从前向后扫描；
若当前区间能接在上一个已选区间之后，就保留它。
```

### Greedy 排序比较器

```cpp
bool compare(const Interval &a, const Interval &b) {
    if (a.end != b.end)
        return a.end < b.end;
    return a.start < b.start;
}
```

[course_direct + visual_direct | code-002, ev-008]

与 DP 正好相反：

- DP 主键是 `start`，因为要组织前驱状态；
- greedy 主键是 `end`，因为要优先占用最少的右侧空间。

终点相同时按起点升序只是主键并列时的次级排序规则；决定贪心选择性质的是终点最早。这里不是说 `std::sort` 具有稳定排序语义。

### 扫描状态

```cpp
int res = 1;
int pre = 0;
```

- `res`：已经保留的互不重叠区间个数；
- `pre`：最后一个已保留区间的下标。[course_direct + visual_direct | ev-008]

扫描转移：

```cpp
for (int i = 1; i < intervals.size(); i++) {
    if (intervals[i].start >= intervals[pre].end) {
        res++;
        pre = i;
    }
}
```

[course_direct + visual_direct | ev-008]

不兼容时直接跳过当前区间。由于当前候选按终点递增，跳过一个结束更晚且与 `pre` 冲突的区间，不会失去比已选 `pre` 更早释放时间轴的机会。

### 空输入为何必须提前返回

greedy 随后会设 `res=1`、`pre=0`，所以非空前提非常重要。屏幕代码先写：

```cpp
if (intervals.size() == 0)
    return 0;
```

因此不会在空数组上虚构一个已选区间或读取 `intervals[0]`。[course_direct + visual_direct | ev-008]

### Greedy 屏幕核心代码

```cpp
bool compare(const Interval &a, const Interval &b) {
    if (a.end != b.end)
        return a.end < b.end;
    return a.start < b.start;
}

class Solution {
public:
    int eraseOverlapIntervals(vector<Interval>& intervals) {
        if (intervals.size() == 0)
            return 0;

        sort(intervals.begin(), intervals.end(), compare);

        int res = 1;
        int pre = 0;
        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i].start >= intervals[pre].end) {
                res++;
                pre = i;
            }
        }

        return intervals.size() - res;
    }
};
```

[course_direct + visual_direct | code-002, ev-008]

### Greedy 复杂度

- 按终点排序：`O(n log n)`；
- 一次扫描：`O(n)`；
- 总时间：`O(n log n)`，课程直接口述确认。[course_direct | ev-009]
- 扫描显式状态只有 `res`、`pre`、`i`，为 `O(1)`；若统计 `std::sort` 内部栈，则空间取决于标准库实现，不能把“扫描常数空间”无条件等同于整个排序过程严格常数空间。[editorial_inference | ev-008]

## DP 与 Greedy 的关系

| 维度       | 动态规划                         | 贪心                                 |
| ---------- | -------------------------------- | ------------------------------------ |
| 目标       | 最多保留互不重叠区间             | 最多保留互不重叠区间                 |
| 排序主键   | `start` 升序                     | `end` 升序                           |
| 状态       | `memo[i]`：以 `i` 结尾的最优长度 | `pre`：最后已选区间，`res`：已选数量 |
| 决策       | 枚举全部合法前驱 `j`             | 只保留结束最早的可行候选             |
| 信息量     | 保存每个末端的最优值             | 只保存当前贪心前沿                   |
| 时间       | `O(n^2)`                         | `O(n log n)`                         |
| 证明核心   | 状态覆盖与最优子结构             | 贪心选择性质与交换论证               |
| 本课完整度 | DP 转移可由代码完整解释          | 只给直觉，完整证明留到 10-03         |

贪心并不是“完全不做动态规划”，而是在额外结构成立时，证明大量 DP 候选状态无需同时保留：只要保留结束时间最早的前沿，就不会损害未来选择空间。[editorial_inference | 基于 ev-005–ev-009]


## 高频陷阱

### 1. 两套比较器混用

```text
DP      -> start 优先
Greedy  -> end 优先
```

按 `start` 排序后直接做 greedy，会失去“结束最早”的选择性质；按 `end` 排序后照搬 DP 状态，也会改变其前驱组织方式。[course_direct + editorial_inference | ev-005, ev-008]

### 2. 把 `memo[i]` 当作前缀最优

若 `memo[i]` 真是 `0...i` 的无条件最优值，转移中应有继承 `memo[i-1]` 的分支。屏幕代码没有，因此必须固定末端。[editorial_inference | ev-005]

### 3. 把 `>=` 写成 `>`

这会错误删除首尾刚好相接的区间，直接违反题意。[course_direct | ev-002, ev-005, ev-008]

### 4. 返回最多保留数而不是最少删除数

两种解法内部先求 `res`，最终都必须返回：

```text
n - res
```

[course_direct + visual_direct | ev-005, ev-008]

### 5. 空输入后仍初始化 `res=1`

必须先处理空数组，否则 greedy 会虚构一个已保留区间。[course_direct + visual_direct | ev-008]

### 6. 用“通过样例”代替证明

测试可以发现反例，无法证明不存在所有更大输入上的反例。贪心题尤其要主动说明选择性质或交换论证。[course_direct + supplemental | ev-009, ev-010]

## 面试回答模板

可以按以下顺序组织回答：

1. **确认语义**：本题 `start<end`，端点相接不算重叠，因此兼容条件允许相等；
2. **等价转化**：最少删除数 = `n -` 最多兼容区间数；
3. **给出基线**：子集枚举为 `O(2^n*n)`；
4. **给出 DP**：按起点排序，定义“以 `i` 结尾”的 `memo[i]`，枚举全部合法前驱，`O(n^2)`；
5. **观察优化**：结束越早，留给后面的空间越大；
6. **给出 greedy**：按终点排序，一次扫描选择兼容区间，`O(n log n)`；
7. **说明证明义务**：用交换论证证明最优解可把首选替换为结束最早区间；若本轮暂不展开，也要明确这是待证明点；
8. **补边界**：空输入、重复区间、端点相接、返回 `n-res`；
9. **补工程项**：显式 `<algorithm>`，统一下标类型。[course_direct + editorial_inference | ev-002–ev-010]
