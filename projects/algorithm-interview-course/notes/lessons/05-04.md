## 为什么使用虚拟头结点

没有虚拟头结点时，第一次交换会改变真实头结点：

```text
head
 ↓
 1 → 2 → 3 → 4

交换后：

head?
 ↓
 2 → 1 → 3 → 4
```

第一对之前没有真实前驱，因此需要单独更新 `head`。后续节点对却都有前驱，逻辑不完全一致。[editorial_inference | 基于 ev-002, ev-003]

加入虚拟头结点后：

```text
dummyHead → 1 → 2 → 3 → 4
     ↑
     p
```

现在第一对 `1, 2` 也有前驱 `p`。每轮都可以把 `p->next` 改为交换后的第一个节点，最后通过 `dummyHead->next` 取得真实返回头。[course_direct + visual_direct | ev-002, ev-003 | 视频 00:58–08:50]

`dummyHead` 不属于题目原链表，只是为了统一边界而创建的辅助节点。屏幕 C++ 代码用 `new` 创建它，因此返回前先保存真实头结点，再 `delete dummyHead`。[course_direct + visual_direct | ev-003 | 视频 04:18–08:50]

## 状态模型

每轮开始时，局部结构可记成：

```text
processed ... → p → node1 → node2 → next → unprocessed ...
```

| 变量        | 本轮角色                 | 取得方式                                  | 本轮结束后的状态       |
| ----------- | ------------------------ | ----------------------------------------- | ---------------------- |
| `dummyHead` | 全链表的虚拟入口         | 初始化 `new ListNode(0)`，再连接到 `head` | 始终不移动             |
| `p`         | 当前待交换节点对的前驱   | 初始为 `dummyHead`                        | 更新为交换后的 `node1` |
| `node1`     | 当前节点对中的第一个节点 | `p->next`                                 | 交换后成为第二个节点   |
| `node2`     | 当前节点对中的第二个节点 | `node1->next`                             | 交换后成为第一个节点   |
| `next`      | 当前节点对之后的链段入口 | `node2->next`                             | 重新接到 `node1->next` |

[course_direct + visual_direct | ev-002, ev-003 | 视频 00:58–08:50]

### 循环前提

只有同时满足以下条件，当前轮才有完整的一对节点：

```cpp
p->next && p->next->next
```

- `p->next` 存在：至少还有一个节点；
- `p->next->next` 存在：至少还有第二个节点。

[visual_direct | ev-003 | 视频 04:18–08:50]

若只剩一个节点，循环停止并保留它；若一个节点都不剩，也直接停止。

### 每轮状态转移

先取得三个局部节点：

```cpp
ListNode* node1 = p->next;
ListNode* node2 = node1->next;
ListNode* next = node2->next;
```

然后执行三处重连：

```cpp
node2->next = node1;
node1->next = next;
p->next = node2;
```

最后把前驱移动到已交换节点对的尾部：

```cpp
p = node1;
```

[course_direct + visual_direct | ev-002, ev-003 | 视频 00:58–08:50]

### 为什么 `p = node1`

交换前：

```text
p → node1 → node2 → next
```

交换后：

```text
p → node2 → node1 → next
             ↑
       下一对的前驱
```

`node1` 在交换后落到这一对的第二位，正好位于下一段未处理链表之前，所以它成为下一轮的 `p`。[course_direct + visual_direct | ev-002, ev-003 | 视频 00:58–08:50]

## 算法步骤

1. 创建 `dummyHead` 并令其 `next = head`。
2. 令 `p = dummyHead`。
3. 当 `p` 后面至少还有两个节点时：
   1. 取 `node1 = p->next`；
   2. 取 `node2 = node1->next`；
   3. 保存 `next = node2->next`；
   4. 令 `node2->next = node1`；
   5. 令 `node1->next = next`；
   6. 令 `p->next = node2`；
   7. 令 `p = node1`。
4. 保存 `retNode = dummyHead->next`。
5. 释放 `dummyHead`。
6. 返回 `retNode`。

## 视频中的完整代码

以下代码按规范化证据中人工核对后的屏幕版本整理：

```cpp
#include <iostream>

using namespace std;

/// Definition for singly-linked list.
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};

class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        ListNode* dummyHead = new ListNode(0);
        dummyHead->next = head;

        ListNode* p = dummyHead;
        while( p->next && p->next->next ){
            ListNode* node1 = p->next;
            ListNode* node2 = node1->next;
            ListNode* next = node2->next;

            node2->next = node1;
            node1->next = next;
            p->next = node2;

            p = node1;
        }

        ListNode* retNode = dummyHead->next;
        delete dummyHead;

        return retNode;
    }
};
```

## 正确性说明

规范化证据将本课正确性方法标为 `state_transition`，但没有给出独立的形式化证明义务。下面按状态转移整理课程逻辑。[course_direct + editorial_inference | 基于 ev-002, ev-003]

### 初始化

`p = dummyHead`。未处理链表从 `p->next` 开始，已处理前缀为空；真实头结点即使参与第一对交换，也有统一前驱。[editorial_inference | 基于 ev-002, ev-003]

### 保持

假设每轮开始时：

- `p` 之前的节点对已正确交换；
- `p->next` 是未处理部分的第一个节点；
- 整条链表从 `dummyHead` 仍然可达。

本轮先保存 `node1`、`node2` 和 `next`，再完成：

```text
p → node1 → node2 → next
```

到：

```text
p → node2 → node1 → next
```

三处连接分别保证：

1. `node2->next = node1`：交换节点对内部顺序；
2. `node1->next = next`：把交换后的节点对接回后续链段；
3. `p->next = node2`：把已处理前缀接到交换后的节点对。

最后 `p = node1`，使 `p` 再次处于下一段未处理链表的前驱位置。[course_direct + visual_direct + editorial_inference | 基于 ev-002, ev-003]

### 终止

每轮处理两个节点，因此未处理节点数严格减少。循环在不足两个节点时结束：

- 剩余 0 个节点：全部完成；
- 剩余 1 个节点：该节点没有配对对象，保持原位。

[course_direct + visual_direct + editorial_inference | 基于 ev-002, ev-003]

### 后置条件

每个完整相邻节点对的内部顺序被交换，节点值没有改变；所有处理过的节点对、可能存在的单个尾节点以及原有后续链段保持连通。`dummyHead->next` 指向交换后的真实头结点。[course_direct + editorial_inference | 基于 ev-001–ev-003]

## 边界情况

### 空链表

`dummyHead->next = NULL`，`p->next` 为假，循环不进入；`retNode` 为 `NULL`。[visual_direct + editorial_inference | 基于 ev-003]

### 单节点链表

`p->next` 存在，但 `p->next->next` 不存在，循环不进入；唯一节点原样返回。[visual_direct + editorial_inference | 基于 ev-003]

### 两个节点

循环恰好执行一次，把这两个节点交换；随后 `p` 位于新的第二个节点，后面不足两个节点，循环结束。[editorial_inference | 基于 ev-002, ev-003]

### 奇数长度

完整节点对全部交换，最后一个未配对节点保持原位。课程动画以五个节点展示了这一结果。[course_direct + visual_direct | ev-002, ev-003 | 视频 00:58–08:50]

### 偶数长度

所有节点都能成对，循环结束时没有未配对尾节点。[editorial_inference | 基于 ev-003]

## 易错点

### 1. 忘记连接前驱

只执行：

```cpp
node2->next = node1;
node1->next = next;
```

还不足以让已处理前缀进入新节点对；必须让 `p->next = node2`。[course_direct + visual_direct | ev-002, ev-003 | 视频 00:58–08:50]

### 2. 忘记连接后继

若交换内部方向后不让 `node1->next` 回到 `next`，后续链段会从返回链表中失联。[course_direct + visual_direct | ev-002 | 视频 00:58–04:18]

### 3. `p` 推进到错误位置

交换后应令 `p = node1`，因为 `node1` 已经成为当前节点对的尾部。若推进到 `node2`，下一轮会重复或错位处理节点。[course_direct + visual_direct + editorial_inference | 基于 ev-002, ev-003]

### 4. 循环条件只检查一个节点

若只检查 `p->next`，奇数长度链表的最后一轮会让 `node1->next` 为 `NULL`，随后对 `node2` 的访问失效。视频代码同时检查两个节点。[visual_direct + editorial_inference | 基于 ev-003]

### 5. 忘记释放虚拟头结点

屏幕代码使用 `new ListNode(0)` 创建 `dummyHead`，因此先保存 `retNode`，再 `delete dummyHead`，最后返回。若语言使用不同的内存管理模型，应按该语言语义处理，不能机械照搬 C++ 的 `delete`。[course_direct + visual_direct + editorial_inference | 基于 ev-003]

### 6. 混淆“节点交换”和“值交换”

本题明确禁止只交换 `val`。即使输出值序列相同，结构没有重连也不满足课程强调的要求。[course_direct + visual_direct | ev-001 | 视频 00:00–00:58]

## 面试表达模板

可以用下面的顺序解释本题：

1. **确认限制**：交换节点本身，不交换节点值。
2. **说明边界统一**：第一对交换会改变头结点，所以增加 `dummyHead`。
3. **定义变量**：`p` 是节点对前驱，`node1/node2` 是待交换节点，`next` 是后继入口。
4. **写局部变换**：`p → node1 → node2 → next` 变为 `p → node2 → node1 → next`。
5. **说明推进**：交换后 `node1` 是这一对尾部，因此 `p = node1`。
6. **说明终止**：只有后面至少两个节点才交换，单个尾节点原样保留。
7. **给出复杂度**：时间 `O(n)`，辅助空间 `O(1)`。
8. **主动验证**：空、单节点、两节点、奇数长度、偶数长度。

- 输入中的节点值均未改写。
