## 一句话结论

把根节点以 `(root, 0)` 入队；每次取出 `(node, level)` 时，若 `level == res.size()` 就创建新层，再把 `node->val` 写入 `res[level]`，最后按左、右顺序把孩子以 `level + 1` 入队。FIFO 顺序保证同层从左到右处理，也保证层号不会跳跃。[course_direct + visual_direct + editorial_inference | 基于 ev-002, ev-003 | 视频 01:02–08:09]

## 为什么队列能形成层序

### FIFO 保存发现顺序

根节点最先入队，也最先出队。处理一个节点时，它的左、右孩子被追加到队尾；队列中原来已经存在的同层节点仍会先于这些下一层节点出队。[visual_direct + editorial_inference | 基于 ev-003]

例如：

```text
初始：[(3, 0)]

处理 3 后：
[(9, 1), (20, 1)]

处理 9 后：
[(20, 1)]

处理 20 后：
[(15, 2), (7, 2)]
```

[editorial_inference | 基于示例 ev-002 与代码 ev-003]

因此队列中的层号按非递减顺序出现：

```text
0, 1, 1, 2, 2, ...
```

同一层内又因代码先压入左孩子、再压入右孩子而保持从左到右顺序。[visual_direct + editorial_inference | 基于 ev-003]

### 为什么要把 `level` 与节点绑定

如果队列只存 `TreeNode*`，仍可以用“每轮先记当前队列长度”的经典方式分层；但本课没有采用该版本。本课直接为每个节点携带层号，因此节点出队时就知道应写入 `res` 的哪一行。[course_direct + visual_direct | ev-003]

不要把另一种按队列长度分层的写法误记成本课屏幕代码。[补充说明]

## 视频中的完整代码

以下为规范化对象 `code-001`。人工核对的状态是 `shown_in_video/complete/not_run`，OCR 不确定项为空。[visual_direct | ev-003 | 视频 02:01–08:09]

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

/// Definition for a binary tree node.
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};

class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {

        vector<vector<int>> res;
        if( root == NULL )
            return res;

        queue< pair<TreeNode*,int> > q;
        q.push( make_pair( root , 0 ) );

        while( !q.empty() ){

            TreeNode* node = q.front().first;
            int level = q.front().second;
            q.pop();

            if( level == res.size() )
                res.push_back( vector<int>() );

            res[level].push_back( node->val );

            if( node->left )
                q.push( make_pair( node->left , level + 1 ) );
            if( node->right )
                q.push( make_pair( node->right , level + 1 ) );
        }

        return res;
    }
};
```

## 队列状态模型

规范化证据记录了两个核心状态对象：[visual_direct | ev-003]

| 对象  | 角色        | 含义                            | 更新方式                                     |
| ----- | ----------- | ------------------------------- | -------------------------------------------- |
| `q`   | work queue  | 尚待处理的 `(TreeNode*, level)` | 弹出队首；把非空孩子以 `level+1` 加入队尾    |
| `res` | accumulator | 已经按层收集的节点值            | 必要时增加一层，再向 `res[level]` 追加当前值 |

### 可用于面试解释的不变量

下面是不在课程中逐字给出的编辑整理：

> 每轮循环开始时，`res` 已按层保存所有已出队节点；`q` 按 BFS 发现顺序保存所有已发现但尚未处理的节点及其正确层号；队列中的层号非递减。[editorial_inference | 基于 ev-003]

初始化时，`res` 为空，`q` 只有 `(root, 0)`，不变量成立。[editorial_inference]

处理 `(node, level)` 时：

1. 为首次遇到的新层建立槽位；
2. 把 `node->val` 追加到该层末尾；
3. 给左右孩子赋予正确的 `level + 1`；
4. 按发现顺序加入队尾。

这些操作保持结果层号、同层顺序和队列层号都正确。[visual_direct + editorial_inference | 基于 ev-003]

队列最终为空时，所有从根可达的节点都已恰好出队一次并写入对应层，因此 `res` 就是层序遍历结果。[editorial_inference | 基于 ev-003]

### 为什么每个节点只处理一次

二叉树中的每个非根节点只有一个父节点，屏幕代码只在处理父节点时把该孩子入队一次；根节点也只在初始化时入队一次。因此在合法树输入下，每个节点恰好入队、出队一次。[editorial_inference | 基于 ev-003]

这条判断依赖输入确实是一棵无环二叉树；若把同一节点从多个位置重复引用，或输入含环，课程代码没有 `visited` 去重。[补充说明]

## 正确性解释

规范化证据将方法记为 `state_transition`，但没有记录课程直接给出的形式化证明义务。以下证明属于编辑整理。[editorial_inference | 基于 ev-003]

### 层号正确

- 根的层号被设为 `0`；
- 若父节点层号正确为 `d`，代码把每个非空孩子标为 `d+1`；
- 由树结构上的归纳，所有入队节点的层号都正确。

[visual_direct + editorial_inference | 基于 ev-003]

### 层内顺序正确

同层父节点按从左到右顺序出队，每个父节点又先压左孩子再压右孩子。FIFO 队列不会让后发现的孩子越过先发现的孩子，因此下一层仍按从左到右处理。[visual_direct + editorial_inference | 基于 ev-003]

### 分组正确

每个节点出队时只执行一次：

```cpp
res[level].push_back(node->val);
```

所以每个节点值进入且只进入其对应层。第一次出现新层时创建数组，之后同层节点追加到同一个数组。[visual_direct + editorial_inference | 基于 ev-003]

### 终止性

对有限二叉树，每个节点至多入队一次；每轮循环固定弹出一个节点。队列经过有限轮后为空，循环终止。[editorial_inference | 基于 ev-003]

## 边界与实现陷阱

### 空树

```cpp
if (root == NULL)
    return res;
```

返回空数组，不进入队列循环。[course_direct + visual_direct | ev-003]

### 单节点树

根以 `(root, 0)` 入队，先建立 `res[0]`，写入根值；左右孩子为空，不再入队，结果为 `[[root->val]]`。[editorial_inference | 基于 ev-003]

### 只有左链或右链

每层只有一个节点，层号依次增加；`level == res.size()` 每次都成立一次，结果有多行、每行一个值。[editorial_inference | 基于 ev-003]

### 必须先扩容再索引

错误顺序：

```cpp
res[level].push_back(node->val);
if (level == res.size())
    res.push_back(vector<int>());
```

第一次处理任何新层都会先访问不存在的下标。屏幕代码把检查放在写入之前。[course_direct + visual_direct + editorial_inference | 基于 ev-003]

### 不要遗漏 `q.pop()`

若只读取队首而不删除，循环会反复处理同一节点并不断加入孩子。屏幕代码在读取 `first/second` 后立即 `pop()`。[visual_direct + editorial_inference | 基于 ev-003]

### 不要改变左右入队顺序

若先入右孩子再入左孩子，仍是按层遍历，但同层输出会变成从右到左，不符合本课示例的输出契约。[visual_direct + editorial_inference | 基于 ev-002, ev-003]

## 面试表达模板

可以按以下顺序说明：

1. **明确输出**：不是普通的一维遍历序列，而是每层一个数组。
2. **选择状态**：队列里保存 `(节点, 层号)`。
3. **初始化**：非空根以 `(root, 0)` 入队。
4. **处理队首**：第一次遇到新层时创建结果数组，再写入节点值。
5. **扩展**：按左、右顺序把非空孩子以 `level+1` 入队。
6. **不变量**：队列按发现顺序保存待处理节点，层号非递减。
7. **边界**：空树直接返回空结果。
