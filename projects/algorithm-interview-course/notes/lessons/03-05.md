## 解法二：计数排序

### 思路

因为值域只有 `{0,1,2}`，先扫描一次数组：

```text
count[0] = 0 的个数
count[1] = 1 的个数
count[2] = 2 的个数
```

再按 `count[0]`、`count[1]`、`count[2]` 的数量依次把 `0`、`1`、`2` 写回原数组。[视频 00:02:58–00:09:05]

### 视频代码

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int count[3] = {0}; // 存放 0, 1, 2 三个元素的频率
        for (int i = 0; i < nums.size(); i++) {
            assert(nums[i] >= 0 && nums[i] <= 2);
            count[nums[i]]++;
        }

        int index = 0;
        for (int i = 0; i < count[0]; i++)
            nums[index++] = 0;
        for (int i = 0; i < count[1]; i++)
            nums[index++] = 1;
        for (int i = 0; i < count[2]; i++)
            nums[index++] = 2;
    }
};
```

## 解法三：三路 partition

### 从三路快排借来的是什么

三路快速排序的 partition 会围绕标定值 `v` 维护“小于 `v`、等于 `v`、大于 `v`”三个区域。本题的值域已经固定为 `0`、`1`、`2`，所以可直接把它们映射为左、中、右三类，并在一次分类过程中完成排序。[视频 00:09:05–00:10:13]

这里没有递归划分子数组，也没有执行完整 QuickSort；只复用了 partition 的多区域维护思想。[视频 00:09:05–00:10:13] [整理推导]

### 指针和四段数组

在每轮循环开始、准备处理 `nums[i]` 时，维护：

```text
[0, zero]        全部为 0
[zero + 1, i)    全部为 1，也就是 [zero + 1, i - 1]
[i, two)         尚未分类
[two, n)         全部为 2，也就是 [two, n - 1]
```

[视频 00:10:13–00:19:23]

课程常把前三个已分类值区称作三个区域；为了完整解释循环，还必须显式保留中间的未知区 `[i,two)`。算法的每次迭代都从这个未知区分类一个位置。[视频 00:10:13–00:13:36] [整理推导]

三个指针的含义是：

- `zero`：0 区最后一个位置；初始化为 `-1`，表示 0 区为空。[视频 00:10:13–00:19:23]
- `i`：未知区的第一个位置，也是当前要分类的元素。[视频 00:10:13–00:19:23]
- `two`：2 区第一个位置；初始化为 `n`，表示 2 区为空。[视频 00:10:13–00:19:23]

初始状态：

```cpp
int zero = -1;
int two = nums.size();
int i = 0;
```

此时 `[0,-1]`、`[0,0)` 和 `[n,n)` 都为空，整个数组 `[0,n)` 都是未知区。[视频 00:10:13–00:19:23] [整理推导]

## 三个分支为什么这样更新

### `nums[i] == 1`：直接扩大 1 区

当前值正是中间区域所需的 `1`，无需交换：

```cpp
i++;
```

原来的位置 `i` 被纳入 `[zero+1,i)`，未知区左端向右缩小一格。[视频 00:10:13–00:19:23]

### `nums[i] == 2`：放进右侧，但 `i` 不动

先把 2 区向左扩一格，再交换：

```cpp
two--;
swap(nums[i], nums[two]);
```

[视频 00:10:13–00:19:23]

交换前的 `nums[two-1]` 属于未知区，而不是已经确认的 0 区、1 区或 2 区。交换后虽然原来的 `2` 已正确进入 `[two,n)`，但换到 `nums[i]` 的值可能是 `0`、`1` 或 `2`，尚未分类；若此时执行 `i++`，就会跳过它并破坏未知区定义。因此 `i` 必须保持不变，让下一轮重新检查同一索引。[视频 00:10:13–00:19:23]

这也是本课最容易写错的非对称点：处理 `2` 时未知区从右侧缩小，靠 `two--` 保证进度，而不是靠 `i++`。[视频 00:13:36–00:19:23] [整理推导]

### `nums[i] == 0`：放进左侧，并让 `i` 前进

先扩大 0 区，再交换：

```cpp
zero++;
swap(nums[zero], nums[i]);
i++;
```

[视频 00:10:13–00:19:23]

为什么这里可以 `i++`？交换前 `[zero+1,i)` 已经全部是 `1`：

- 若 1 区非空，`zero++` 后的 `nums[zero]` 原本是已分类的 `1`，交换到 `nums[i]` 后可以直接并入 1 区；
- 若 1 区为空，则 `zero + 1 == i`，交换是当前位置与自身交换，0 区扩大后未知区仍安全地从 `i+1` 开始。

因此换到当前扫描位置的值不是未知值，不必再次检查。[视频 00:10:13–00:19:23] [整理推导]

### 非法值

在 `else` 分支中，视频代码用：

```cpp
assert(nums[i] == 0);
```

这是因为题目约束排除了 0、1、2 之外的值。若断言被编译掉，任意“既非 1 又非 2”的非法值都会走 0 分支，因此这段代码仍以合法输入契约为前提。[视频 00:13:36–00:19:23] [补充说明]

## 视频中的三路 partition 代码

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int zero = -1;          // nums[0...zero] == 0
        int two = nums.size();  // nums[two...n-1] == 2
        for (int i = 0; i < two; ) {
            if (nums[i] == 1) {
                i++;
            } else if (nums[i] == 2) {
                two--;
                swap(nums[i], nums[two]);
            } else {
                assert(nums[i] == 0);
                zero++;
                swap(nums[zero], nums[i]);
                i++;
            }
        }
    }
};
```

### 核心清单

- 通用排序是 `O(n log n)` 可行基线，但视频未说明其额外空间。[视频 00:00:27–00:02:58]
