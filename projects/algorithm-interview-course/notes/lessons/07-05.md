### 2. 根到叶路径

路径：

- 从当前树根开始；
- 沿父子边向下；
- 在左右孩子均为空的叶节点结束。

[course_direct + visual_direct | ev-002, ev-004]

输出用 `"->"` 连接节点值，例如：

```text

```

[visual_direct | ev-002, ev-004]

### 3. 自顶向下拆分，自底向上组合

对当前根：

```text
先求左子树的全部路径 leftS
再求右子树的全部路径 rightS
最后给每条子路径加上当前根前缀
```

[course_direct + visual_direct | ev-003, ev-004]

递归调用沿树向下分解，路径字符串沿返回方向向上构造。[course_direct + editorial_inference | 基于 ev-003]

### 4. 返回集合而不是单条路径

函数返回 `vector<string>`，因为一棵树可能有多个叶节点，每个叶节点对应一条根到叶路径。[visual_direct | ev-002, ev-004]

## 屏幕完整代码

视频屏幕原码 `code-001`：

```cpp
/// Definition for a binary tree node.
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};

class Solution {
public:
    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> res;
        if (root == NULL)
            return res;

        if (root->left == NULL && root->right == NULL) {
            res.push_back(to_string(root->val));
            return res;
        }

        vector<string> leftS = binaryTreePaths(root->left);
        for (int i = 0; i < leftS.size(); i++)
            res.push_back(to_string(root->val) + "->" + leftS[i]);

        vector<string> rightS = binaryTreePaths(root->right);
        for (int i = 0; i < rightS.size(); i++)
            res.push_back(to_string(root->val) + "->" + rightS[i]);

        return res;
    }
};
```

## 正确性解释

课程强调函数语义并用动画、代码说明组合，没有给出形式化证明。下面使用结构归纳整理。

### 1. 递归契约

对任意节点 `root`：

```text
binaryTreePaths(root)
返回以 root 为起点、以其子树叶节点为终点的全部路径字符串
```

[course_direct | ev-004]

### 2. 空树边界

当 `root == NULL` 时，不存在以它为起点的路径，返回空向量，且不会解引用空指针。[course_direct + editorial_inference | 基于 ev-004]

### 3. 叶节点基例

当左右孩子均为空时，唯一根到叶路径只包含当前节点。`to_string(root->val)` 正好表示该路径。[course_direct + editorial_inference | 基于 ev-004]

### 4. 归纳假设

假设：

- `binaryTreePaths(root->left)` 正确返回左子树所有根到叶路径；
- `binaryTreePaths(root->right)` 正确返回右子树所有根到叶路径。

[editorial_inference]

### 5. 组合保持

每条当前根到叶路径的第一条边必然进入左孩子或右孩子。对任一子树返回路径，加上：

```text
to_string(root->val) + "->"
```

即可得到当前根到同一叶节点的路径。[editorial_inference | 基于 code-001]

左、右两组都被遍历并追加，所以不会遗漏任一结构上的根到叶路径；代码也不会生成在叶节点前提前结束的路径。[editorial_inference]

若树中存在不同节点路径但节点值序列完全相同，两个输出字符串可能相同；本证明说明的是“每条节点路径都被构造”，不额外声称字符串值全局唯一。[补充说明]

### 6. 终止性

每次递归都进入严格更小的左或右子树；有限树最终到达空树或叶节点并直接返回。[editorial_inference | 基于 code-001]

## 时间与空间复杂度

### 课程直接证据

课程没有给出时间或空间复杂度，也没有分析字符串复制和最终输出长度。规范化对象的顶层复杂度保持 `null`。[补充说明]

### 为什么不能只写 `O(n)`

若只把“访问节点”视为单位操作，树结构遍历会访问每个节点一次。但屏幕实现还会：

- 把整数转换为字符串；
- 在每个祖先层级拼接前缀；
- 构造新的字符串；
- 把字符串放入不同层级的结果向量。

[editorial_inference | 基于 code-001]

这些工作取决于路径数量、路径深度、节点值字符数和中间字符串长度，不能被常数时间节点访问完全概括。

### 输出敏感的编辑口径

定义：

```text
n = 节点数
h = 树高
L = 最终返回的所有路径字符串字符总数
C = 整个递归过程中处理的中间与最终字符串字符总量
```

则可用下面的安全口径描述：

```text
结构遍历工作：O(n)
含字符串构造的总时间：O(n + C)
递归栈：O(h)
最终输出至少占：O(L)
```

[editorial_inference]

由于同一叶路径的后缀会在多个祖先层级被再次拼接，`C` 可能大于最终输出量 `L`。因此不应把这份具体实现未经说明地简化为 `O(n+L)`。[editorial_inference]

运行时还会同时保存 `leftS`、`rightS`、`res` 等中间向量。若讨论总空间，除递归栈外还必须计入最终输出和峰值中间字符串存储；不能只写 `O(h)`。[editorial_inference]

这些分析均不是课程直接结论。[补充说明]

## 边界条件、易错点与测试

### 边界条件

1. **空树**：返回 `[]`。[visual_direct | ev-004]
2. **单节点树**：返回只含当前值的一个字符串。[visual_direct + editorial_inference | 基于 ev-004]
3. **只有左子树**：`rightS` 为空，不影响已构造的左侧路径。[editorial_inference | 基于 code-001]
4. **只有右子树**：`leftS` 为空，右侧循环仍构造完整路径。[editorial_inference | 基于 code-001]
5. **叶节点**：必须直接返回，否则进入两个空孩子后会丢失自身路径。[editorial_inference]
6. **重复节点值**：不同节点路径的字符串可能相同，代码不去重。[补充说明]

### 易错点

- 没有先定义递归函数返回值；
- 把叶节点错误写成只有一个孩子为空；
- 空树时继续访问 `root->left`；
- 左循环误用 `rightS`，或右循环误用 `leftS`；
- 拼接顺序写成 `child + "->" + root`；
- 漏掉箭头或使用错误字符串；
- 循环上界和索引来自不同向量；
- 只返回一条路径而不是所有路径；
- 把课程示例输出写成本项目运行结果；
