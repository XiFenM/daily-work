## 核心概念

### 1. 栈

栈是后进先出（LIFO）的数据结构。本题中，越晚出现的左括号越处于更内层，也越应该先与后续右括号匹配；因此“最近尚未匹配的左括号”自然位于栈顶。[course_direct + visual_direct | ev-003 | 视频 01:46–05:53]

这里的栈不是保存所有已经看过的字符，而只保存：

> 已经出现、但还没有被对应右括号关闭的左括号。

[course_direct + editorial_inference | 基于 ev-003, ev-004 | 视频 01:46–11:27]

### 2. 嵌套层次与最近匹配

课程用类似下面的合法序列演示：

```text
{ [ ( ) ] }
```

扫描过程为：

1. `{` 入栈；
2. `[` 入栈；
3. `(` 入栈；
4. `)` 必须先匹配栈顶 `(`；
5. `]` 再匹配栈顶 `[`；
6. `}` 最后匹配栈顶 `{`；
7. 扫描结束，栈为空。

[course_direct + visual_direct | ev-003 | 视频 01:46–05:53]

这说明合法性不仅要求左右括号数量对应，还要求关闭顺序与嵌套层次一致。[course_direct + editorial_inference | 基于 ev-002, ev-003]

### 3. 失败的两种来源

课程代码直接处理了两类失败：

1. **右括号没有可匹配对象**：当前字符是右括号，但栈已经为空；
2. **右括号类型错误**：栈非空，但栈顶左括号与当前右括号不是一对。

[course_direct + visual_direct | ev-003, ev-004 | 视频 01:46–11:27]

此外，遍历结束后还可能出现第三类失败：

3. **残留左括号**：字符串已经结束，但栈仍非空。

### 屏幕代码

以下代码来自规范化对象 `code-001`，关键 token 已用目标帧复核：

```cpp
#include <iostream>
#include <cassert>
#include <string>
#include <stack>

using namespace std;

class Solution {
public:
    bool isValid(string s) {
        stack<char> stack;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(' || s[i] == '{' || s[i] == '[') {
                stack.push(s[i]);
            } else {
                if (stack.size() == 0) {
                    return false;
                }
                char c = stack.top();
                stack.pop();

                char match;
                if (s[i] == ')') {
                    match = '(';
                } else if (s[i] == ']') {
                    match = '[';
                } else {
                    assert(s[i] == '}');
                    match = '{';
                }

                if (c != match) {
                    return false;
                }
            }
        }

        if (stack.size() != 0) {
            return false;
        }

        return true;
    }
};
```

条件：

### 遇到右括号且栈为空

条件：

```cpp

```

更新：

```cpp

```

这避免对空栈执行 `top()`，同时表达“当前右括号没有任何先前左括号可以匹配”。[course_direct + visual_direct | ev-004 | 视频 05:53–11:27]

### 遇到右括号且栈非空

先取出并弹出最近的左括号：

```cpp
char c = stack.top();
stack.pop();
```

再根据当前右括号计算期望左括号：

```text
) → (
] → [
} → {
```

若 `c != match`，立即返回 `false`；否则继续扫描。[course_direct + visual_direct | ev-003, ev-004 | 视频 01:46–11:27]

### 扫描结束

```cpp

    return false;
```

因为剩余元素代表尚未关闭的左括号。只有栈为空时才能返回 `true`。[course_direct + visual_direct | ev-004 | 视频 05:53–11:27]

### 初始化

### 保持

- 若 `s[i]` 是左括号，把它压到栈顶，正好记录新的最内层未匹配括号；

- 若栈为空或类型不匹配，当前前缀已经不可能成为合法括号串，立即返回 `false` 是安全的。

## 边界与实现陷阱

### 1. 先判空，再取栈顶

错误顺序：

```cpp
char c = stack.top();
if (stack.empty()) ...
```

在字符串以右括号开头时会先访问空栈。课程代码正确地把判空放在 `top()` 之前。[course_direct + visual_direct | ev-004 | 视频 05:53–11:27]

### 2. 不能只比较数量

`"([)]"` 的左右括号数量相等，但嵌套顺序错误。栈顶匹配检查保留了顺序信息，而简单计数做不到这一点。[course_direct + visual_direct + editorial_inference | 基于 ev-002, ev-003]

### 3. 循环结束不能无条件成功

`"(("` 在扫描过程中不会遇到错误右括号，但最后栈中仍有两个元素。若循环后直接 `return true`，就会误判。[course_direct + visual_direct | ev-004 | 视频 05:53–11:27]

### 4. `else` 分支依赖六字符题面

屏幕代码把剩余情况视为 `}`，并用 `assert` 检查。若接口扩展到任意字符，应明确拒绝、忽略或分类处理，不能默认沿用当前分支。[visual_direct + editorial_inference | 基于 ev-002, ev-004]
