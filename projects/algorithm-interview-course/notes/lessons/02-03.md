## 核心概念与定义

### 1. 复杂度分析的对象是执行次数的增长

课程中的每个例子都可以归结为同一个问题：选定一个会重复发生的基本操作，求它随输入规模 `n` 的执行次数，再保留增长最快的部分。[视频 00:00:00–00:19:20] [整理推导]

这也解释了为什么不能只数 `for` 或 `while` 的层数：

- 两层循环中，内层若固定执行 30 次，总次数只是 `30n`。[视频 00:05:13–00:06:31]
- 一层循环若每次把变量翻倍，只执行约 `log n` 次，而不是 `n` 次。[视频 00:14:46–00:16:46]
- 一层循环若终止条件是 `x * x <= n`，最多推进到 `sqrt(n)`。[视频 00:16:46–00:19:20]

### 2. 常数时间 `O(1)`

`swapTwoInts` 只包含三次固定赋值。无论调用者处理的数据集合多大，这次交换本身的操作数都不随 `n` 增加，因此记为 `O(1)`。[视频 00:00:00–00:00:30]

这里的 `O(1)` 表示“相对于输入规模不增长”，不是“真实运行只花一条指令”或“耗时一定为 1”。[整理推导]

### 3. 线性时间 `O(n)`

`sum` 顺序累加，工作量随参数 `n` 线性增加；`reverse` 只遍历字符串前半部分，约执行 `n/2` 次交换，但 `1/2` 是常数系数，因此仍记作 `O(n)`。[视频 00:00:30–00:02:12]

课程由此强化上一节 Big O 的化简规则：`cn` 中固定的 `c` 不改变增长阶。[视频 00:00:30–00:02:12]

### 4. 平方时间 `O(n^2)`

选择排序在第 `i` 轮从尚未排好序的后缀中寻找最小元素。比较次数依次为 `n-1, n-2, …, 0`，求和后主导项为 `n^2/2`，因此为 `O(n^2)`。[视频 00:02:12–00:05:13]

关键不在于代码“恰好写了两层循环”，而在于内层工作量随剩余数据规模变化，累加后形成二次项。[视频 00:02:12–00:05:13] [整理推导]

### 5. 对数时间 `O(log n)`

当每轮把当前问题规模除以固定常数时，需要的轮数是对数级：

- 二分查找每轮舍弃一半搜索区间，需要约 `log_2 n` 轮。[视频 00:06:31–00:09:01]
- 整数转字符串的循环每轮执行 `num /= 10`，轮数与十进制位数一致，即约 `log_10 n`。[视频 00:09:01–00:11:45]

课程随后用换底公式说明，`log_a n` 与 `log_b n` 之间只相差一个与 `n` 无关的常数因子，因此在 Big O 中通常统一写成 `O(log n)`。[视频 00:11:45–00:14:46]

### 6. 线性对数时间 `O(n log n)`

`hello` 的外层变量 `sz` 每轮执行 `sz += sz`，也就是按 `1, 2, 4, 8, …` 倍增，外层约执行 `log_2 n` 次；每一轮内层再执行约 `n` 次输出，总工作量为 `n log_2 n`，记为 `O(n log n)`。[视频 00:14:46–00:16:46]

### 7. 平方根时间 `O(sqrt(n))`

`isPrime` 的循环从 `x = 2` 开始，终止条件是 `x * x <= n`，等价于只让 `x` 增长到 `sqrt(n)` 附近。由于 `x` 每轮加 1，试除次数最多与 `sqrt(n)` 同阶，所以时间复杂度为 `O(sqrt(n))`。[视频 00:16:46–00:19:20]

## 分析方法演进

本课没有单题解法的逐步优化。下面是从九个例子抽取出的通用分析流程，属于编辑性整理：[整理推导]

1. **定义规模变量**：明确 `n` 是元素数、字符串长度还是整数的数值大小。
2. **选择主导操作**：例如比较、交换、除法或输出。
3. **写出循环变量轨迹**：检查初值、终止条件和每轮更新，而不是只数循环层。
4. **计算单轮与总轮数**：嵌套结构要把各层实际工作量相乘或求和。
5. **得到可解释的表达式**：如 `30n`、`n(n-1)/2`、`n log n`。
6. **按 Big O 化简**：忽略固定常数与低阶项，但保留决定增长速度的主导项。
7. **回查边界与假设**：复杂度结论不能替代对输入合法性和实现缺陷的检查。

### 1. 固定操作：`swapTwoInts`

```cpp
void swapTwoInts(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}
```

三次赋值的数量固定，故时间复杂度为 `O(1)`。[视频 00:00:00–00:00:30]

### 2. 线性推进：`sum` 与 `reverse`

```cpp
int sum(int n) {
    int ret = 0;
    for (int i = 0; i <= n; i++)
        ret += i;
    return ret;
}

void reverse(string &s) {
    int n = s.size();
    for (int i = 0; i < n / 2; i++)
        swap(s[i], s[n - 1 - i]);
}
```

`sum` 的循环次数与 `n` 线性相关；`reverse` 约执行 `n/2` 次交换。两者都为 `O(n)`，后者展示了常数系数在 Big O 中被忽略。[视频 00:00:30–00:02:12]

### 3. 累加变化的内层规模：`selectionSort`

```cpp
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[minIndex])
                minIndex = j;

        swap(arr[i], arr[minIndex]);
    }
}
```

第 0 轮比较 `n-1` 次，第 1 轮比较 `n-2` 次，直至 0 次；总和的主导项为 `n^2`，所以为 `O(n^2)`。[视频 00:02:12–00:05:13]

### 4. 常数内层循环：`printInformation`

```cpp
void printInformation(int n) {
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= 30; j++)
            cout << "Class " << i << " - " << "No. " << j << endl;
    return;
}
```

内层固定执行 30 次，总输出次数为 `30n`，因此是 `O(n)` 而不是 `O(n^2)`。[视频 00:05:13–00:06:31]

### 5. 按比例缩小：`binarySearch`

```cpp
int binarySearch(int arr[], int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] > target) r = mid - 1;
        else l = mid + 1;
    }
    return -1;
}
```

每轮排除约一半候选，区间规模按 `n → n/2 → n/4 → … → 1` 变化，因此轮数为 `log_2 n`，时间复杂度为 `O(log n)`。[视频 00:06:31–00:09:01]

### 6. 按十进制位数推进：`intToString`

```cpp
string intToString(int num) {
    string s = "";
    while (num) {
        s += '0' + num % 10;
        num /= 10;
    }
    reverse(s);
    return s;
}
```

循环每轮去掉一位十进制数字，执行约 `log_10 n` 次；随后翻转的长度也是数字位数，所以课程结论为 `O(log n)`。[视频 00:09:01–00:14:46]

这段简化实现没有正确处理负数和 0，视频明确把它们作为边界陷阱指出。[视频 00:11:45–00:14:46]

### 7. 对数轮数乘线性工作：`hello`

```cpp
void hello(int n) {
    for (int sz = 1; sz < n; sz += sz)
        for (int i = 1; i < n; i++)

}
```

外层 `sz` 每次翻倍，约运行 `log_2 n` 轮；每轮内层约执行 `n` 次，因此总复杂度为 `O(n log n)`。[视频 00:14:46–00:16:46]

### 8. 非线性终止条件：`isPrime`

```cpp

    for (int x = 2; x * x <= n; x++)
        if (n % x == 0)

    return true;

```

循环只推进到 `sqrt(n)`，所以时间复杂度为 `O(sqrt(n))`。视频同时指出，当 `n <= 1` 时循环不会进入，函数会直接返回 `true`，这不符合素数判断的预期。[视频 00:16:46–00:19:20]

## 公式推导

### 1. 选择排序的比较次数

视频展示的完整推导为：[视频 00:02:12–00:05:13]

```text
(n - 1) + (n - 2) + (n - 3) + ... + 0
= ((0 + n - 1) * n) / 2
= (1/2) * n * (n - 1)
= (1/2) * n^2 - (1/2) * n
```

化简 Big O 时：

1. 二次项比一次项增长更快，保留主导项 `n^2`。
2. 固定系数 `1/2` 不随 `n` 改变，忽略该系数。
3. 得到 `O(n^2)`。[视频 00:02:12–00:05:13]

### 2. 对数换底

视频给出的换底关系为：[视频 00:11:45–00:14:46]

```text
log_a N = log_a b * log_b N
```

当底数 `a`、`b` 固定时，`log_a b` 是常数，因此 `log_a N` 与 `log_b N` 只相差常数倍。Big O 忽略这一常数倍，所以二分查找的 `log_2 n` 和十进制位数的 `log_10 n` 都可写作 `O(log n)`。[视频 00:06:31–00:14:46]

### 示例一：二分查找的轮数

若初始搜索区间规模为 `n`，未命中时每轮只保留一半：[视频 00:06:31–00:09:01]

```text
n → n/2 → n/4 → ... → 1
```

求“除以 2 多少次后到 1”，答案是 `log_2 n`，因此二分查找的循环轮数为对数级。[视频 00:06:31–00:09:01]

### 示例二：为什么双重循环仍可能是线性

`printInformation` 对每个班级固定输出 30 个编号。如果班级数从 `n` 增到 `2n`，总输出从 `30n` 增到 `60n`，只增长 2 倍；30 没有随输入扩大，所以增长阶仍是线性的。[视频 00:05:13–00:06:31] [整理推导]

### 示例三：为什么单层循环可能是平方根级

`isPrime` 的 `x` 虽然每轮只加 1，但终点不是 `n`，而是由 `x * x <= n` 决定。把条件改写成 `x <= sqrt(n)`，就能直接看到循环上界。[视频 00:16:46–00:19:20]

1. **看到双重循环就写 `O(n^2)`**：没有检查内层循环是常数 30 次，或外层变量是否倍增。[视频 00:05:13–00:06:31] [视频 00:14:46–00:16:46]

4. **忘记化简规则的适用边界**：固定常数可以忽略，但不能把会随 `n` 增长的因子当作常数，例如 `log n`。[视频 00:11:45–00:16:46] [整理推导]
5. **把复杂度正确当成功能正确**：即使复杂度分析无误，代码仍可能在 0、负数或 `n <= 1` 上失败。[视频 00:11:45–00:19:20]

## 复习区

### 核心清单

- 复杂度来自操作次数随 `n` 的增长，不来自循环层数的外观。[视频 00:00:00–00:19:20]
- `n/2` 与 `30n` 仍是 `O(n)`，因为固定系数被忽略。[视频 00:00:30–00:06:31]
- 变化的内层规模需要求和；选择排序得到 `n(n-1)/2`，即 `O(n^2)`。[视频 00:02:12–00:05:13]
- 每轮把规模除以固定常数，通常产生 `O(log n)`；对数底数在 Big O 中可省略。[视频 00:06:31–00:14:46]
- 倍增外层 `log n` 轮、每轮线性工作，组合成 `O(n log n)`。[视频 00:14:46–00:16:46]
- 终止条件 `x * x <= n` 把单层循环限制在 `O(sqrt(n))`。[视频 00:16:46–00:19:20]
- 性能分析和功能正确性是两张检查表。[视频 00:11:45–00:19:20] [整理推导]
