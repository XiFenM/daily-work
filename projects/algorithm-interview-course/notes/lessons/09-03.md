## 一句话结论

定义 `best(n)` 为把 `n` 至少拆成两部分后的最大乘积。枚举第一部分 `i`，余数要在“不拆”与“继续最优拆分”之间选择，因此：

```text
best(n) = max over 1 <= i < n of
          { i * (n - i), i * best(n - i) }
```

记忆化自顶向下缓存 `best(n)`；自底向上按 `i=2...n` 填表。[course_direct + visual_direct | ev-005, ev-006]

## 从暴力搜索到重叠子问题

最直接的思路是枚举第一段，再递归处理剩余部分。全部分割方式形成一棵树，课程给出暴力回溯的时间复杂度 `O(2^n)`。[course_direct | ev-002]

在 `split(4)` 的递归树中，相同的 `split(2)` 会从不同分割路径重复出现；一般化到 `split(n)` 后，`split(n-2)` 等子状态也会重复。[course_direct + visual_direct | ev-003]

重叠子问题只说明“缓存可能节省工作”，还不足以说明如何组合最优答案；后者需要最优子结构。[editorial_inference]

## 最优子结构

课程给出的含义是：通过求子问题的最优解，可以获得原问题的最优解。[course_direct + visual_direct | ev-004]

在本题中，一旦固定第一部分 `i`：

- 余数可保持为整体 `n-i`；
- 或把余数继续分割，并取它的最佳分割乘积。

对所有 `i` 取最大值，就覆盖原问题的所有首段选择。[course_direct + editorial_inference | ev-005, ev-006]

## 状态定义：强制拆分语义

定义：

```text
best(n) = 把 n 至少拆成两部分后，能得到的最大乘积
```

[course_direct + visual_direct | code-001, ev-005]

这一定义带来一个容易漏掉的区别：`best(n-i)` **强制**继续拆分余数，而题目的一种合法方案可能让余数保持整体。因此每个分割点必须比较：

```text
i * (n - i)       // 余数不继续拆
i * best(n - i)   // 余数继续最优拆分
```

[course_direct + visual_direct | ev-005, ev-006]

例如求 `best(4)` 时取 `i=1`：

- 不继续拆：`1 * 3 = 3`；
- 继续拆：`1 * best(3) = 2`。

若只保留继续拆的候选，就会漏掉乘积 3。最终其他分割点能得到答案 4，但这个局部例子已说明两类候选不能凭状态定义合并。[editorial_inference]

## 版本一：记忆化搜索（自顶向下）

### 屏幕核心代码

```cpp
class Solution {
private:
    vector<int> memo;

    int max3(int a, int b, int c) {
        return max(a, max(b, c));
    }

    int breakInteger(int n) {
        if (n == 1)
            return 1;

        if (memo[n] != -1)
            return memo[n];

        int res = -1;
        for (int i = 1; i <= n - 1; i++)
            res = max3(res,
                       i * (n - i),
                       i * breakInteger(n - i));

        memo[n] = res;
        return res;
    }

public:
    int integerBreak(int n) {
        assert(n >= 2);
        memo = vector<int>(n + 1, -1);
        return breakInteger(n);
    }
};
```

[visual_direct | code-001, ev-005]

### 状态五要素

| 要素     | 定义                                                                 |
| -------- | -------------------------------------------------------------------- |
| 状态     | `breakInteger(n)` / `memo[n]`：`n` 强制拆分后的最大乘积              |
| 初始化   | `memo` 长度 `n+1`，初值 `-1`；辅助基本值 `breakInteger(1)=1`         |
| 转移     | 枚举 `i=1...n-1`，取 `i*(n-i)` 与 `i*breakInteger(n-i)` 的全局最大值 |
| 求值顺序 | 自顶向下；缓存命中直接返回                                           |
| 答案     | 公开入口返回 `breakInteger(n)`                                       |

[course_direct + visual_direct | ev-005]

### 缓存不变量（整理）

`memo[k] != -1` 时，它保存 `k` 在“至少拆两部分”契约下的最大乘积；缓存值不会被另一种“允许不拆”的状态语义污染。[editorial_inference | 基于 ev-005]

## 版本二：自底向上动态规划

### 屏幕核心代码

```cpp
class Solution {
private:
    int max3(int a, int b, int c) {
        return max(a, max(b, c));
    }

public:
    int integerBreak(int n) {
        assert(n >= 2);
        vector<int> memo(n + 1, -1);

        memo[1] = 1;
        for (int i = 2; i <= n; i++) {
            for (int j = 1; j <= i - 1; j++) {
                memo[i] = max3(memo[i],
                               j * (i - j),
                               j * memo[i - j]);
            }
        }
        return memo[n];
    }
};
```

[visual_direct | code-002, ev-006]

### 动态规划五要素

| 要素     | 定义                                                      |
| -------- | --------------------------------------------------------- |
| 状态     | `memo[i]`：`i>=2` 时，`i` 强制拆分后的最大乘积            |
| 初始化   | `memo[1]=1` 是递推辅助值；其余先为 `-1`                   |
| 转移     | `memo[i]=max(memo[i], j*(i-j), j*memo[i-j])`              |
| 遍历顺序 | 外层 `i=2...n`；内层 `j=1...i-1`，保证 `memo[i-j]` 已存在 |
| 答案     | `memo[n]`                                                 |

[course_direct + visual_direct | ev-006]

### 循环不变量（整理证明）

进入外层索引 `i` 时，`memo[2...i-1]` 已分别保存对应整数的最佳强制拆分乘积：

1. `memo[1]=1` 提供递推辅助值；
2. 对固定 `i`，内层枚举所有第一段 `j`；
3. 每个 `j` 同时覆盖余数保持整体与继续拆分两类候选；
4. 内层结束后，`memo[i]` 覆盖全部合法首段选择；
5. 外层结束时 `memo[n]` 即题目答案。

[editorial_inference | 基于 ev-005, ev-006]

## 为什么 `breakInteger(1)=1` 不是题目答案

公开题目要求至少拆成两部分，并且入口断言 `n>=2`。因此：

- `breakInteger(1)=1` 只是让 `i * breakInteger(1)` 在递推中可组合；
- `memo[1]=1` 也是内部辅助身份；
- 不能据此声称“输入 1 的合法答案是 1”；
- 状态表里的辅助值和公开接口的合法答案域可以不同。

[前两项 visual_direct，解释为 editorial_inference | ev-005, ev-006]

## 正确性说明

课程直接强调两类候选和最优子结构，但没有给出完整归纳证明。可整理如下：[editorial_inference]

### 1. 候选完备

任意合法分割都有一个第一部分 `j`。去掉它后，余数要么不再拆，要么继续拆；转移分别覆盖这两种情况。

### 2. 候选合法

`j` 与 `i-j` 都是正整数；若使用 `memo[i-j]`，它按状态契约代表余数的合法强制拆分结果。

### 3. 最优子结构

对固定 `j`，若决定继续拆余数，用余数的非最优拆分不可能优于其最优拆分，所以只需组合 `memo[i-j]`。

### 4. 全局最优

枚举完 `j=1...i-1` 后，所有首段选择均被覆盖；取最大值即 `i` 的最优解。

### 5. 依赖顺序

自底向上版本只读取 `i-j < i` 的状态，外层递增保证依赖先算；记忆化版本参数严格变小，最终到达辅助基本值 1。

辅助值：best(1)=1，仅供递推

动态规划：i 从 2 到 n，j 从 1 到 i-1

整理空间：O(n)
关键陷阱：不能只考虑继续拆余数
