## 基线解法：用辅助向量保存非零元素

### 第一步：按原顺序收集非零元素

从左到右扫描 `nums`。若 `nums[i] != 0`，就把它追加到 `nonZeroElements`：

```cpp
vector<int> nonZeroElements;
for (int i = 0; i < nums.size(); i++) {
    if (nums[i]) {
        nonZeroElements.push_back(nums[i]);
    }
}
```

[视频 00:05:35–00:08:01]

由于扫描方向是从左到右、追加方向也是从容器尾部依次加入，辅助向量中的非零元素顺序与原数组一致。[视频 00:05:35–00:08:01] [整理推导]

### 第二步：把非零元素写回数组前部

顺序遍历 `nonZeroElements`，用其第 `i` 个元素覆盖 `nums[i]`：

```cpp
for (int i = 0; i < nonZeroElements.size(); i++) {
    nums[i] = nonZeroElements[i];
}
```

[视频 00:06:05–00:08:01]

设非零元素个数为 `k`，这一步完成后，`nums[0…k-1]` 就是原数组全部非零元素的稳定序列。[视频 00:05:35–00:08:01] [整理推导]

### 第三步：把剩余位置填成零

数组总长度仍是 `n`。从索引 `k` 到 `n-1` 统一写入 `0`：

```cpp
for (int i = nonZeroElements.size(); i < nums.size(); i++) {
    nums[i] = 0;
}
```

[视频 00:06:05–00:08:01]

这样既没有改变数组长度，又把恰好 `n-k` 个零放到了末尾。[视频 00:05:35–00:08:01] [整理推导]

## 视频中的完整代码

以下代码按规范化视频证据转录。证据记录为完整、无 OCR 不确定项，但本项目未编译或执行。[视频 00:06:05–00:08:01] [视频 00:09:39–00:10:40]

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {

        vector<int> nonZeroElements;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i]) {
                nonZeroElements.push_back(nums[i]);
            }
        }

        for (int i = 0; i < nonZeroElements.size(); i++) {
            nums[i] = nonZeroElements[i];
        }

        for (int i = nonZeroElements.size(); i < nums.size(); i++) {
            nums[i] = 0;
        }
    }
};
```

这里的 `if (nums[i])` 利用 C++ 中零值为假、非零值为真的条件语义，因此负数等非零整数也会被保留；这是对展示代码的语言层解释，不是视频单独展示的边界用例。[视频 00:06:05–00:08:01] [整理推导]

## 复杂度分析

设数组长度为 `n`，非零元素个数为 `k`。[整理推导]

### 时间复杂度 `O(n)`

- 收集非零元素扫描 `n` 个位置；
- 写回非零元素执行 `k` 次；
- 尾部补零执行 `n-k` 次。

总操作轮数按这三段循环计算为：

```text
n + k + (n - k) = 2n
```

忽略常数后为 `O(n)`，与课程给出的结论一致。[视频 00:06:05–00:08:01] [视频 00:11:50–00:12:22] [整理推导]
