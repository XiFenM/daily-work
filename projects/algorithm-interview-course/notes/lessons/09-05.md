## 一句话结论

定义：

```text
F(i,c) = 只使用物品 [0...i]，且背包容量为 c 时能获得的最大价值
```

对第 `i` 件物品，完整且互斥的选择只有两类：

```text
不选 i：F(i-1,c)
选 i：v[i] + F(i-1,c-w[i])，前提是 c >= w[i]
```

因此：

```text
F(i,c) = max(F(i-1,c), v[i] + F(i-1,c-w[i]))
```

第二支仍读取 `i-1`，正是“每件物品最多一次”的代码体现。[course_direct + visual_direct | formula-001, ev-005]

## 题目模型：为什么叫 0-1 背包

课程题面可写为：

```text
背包容量：C
物品数量：n
第 i 件物品：重量 w(i)，价值 v(i)
约束：总重量不超过 C；每件物品最多选择一次
目标：使所选物品总价值最大
```

[course_direct + visual_direct | ev-002, ev-003]

“0-1”描述的是每件物品的选择次数：

```text
x_i ∈ {0,1}
```

即不选或选一次。把它写成数学形式是：

```text
maximize  Σ v[i] * x_i
subject to Σ w[i] * x_i <= C
           x_i ∈ {0,1}
```

[editorial_inference | 对课程题意的等价形式化]

课程没有在当前结构化证据中给出 `C`、`w[i]`、`v[i]` 的平台数值上界，因此笔记不补造外部约束。[补充说明]

## 为什么单位价值贪心会失败

课程考虑看似自然的策略：

```text
按 v[i] / w[i] 从大到小选择
```

示例为：

| 物品 | 重量 | 价值 | 单位价值 |
| ---- | ---: | ---: | -------: |
| 0    |    1 |    6 |        6 |
| 1    |    2 |   10 |        5 |
| 2    |    3 |   12 |        4 |

背包容量：

```text
C = 5
```

[course_direct + visual_direct | ev-004]

按单位价值贪心先选物品 0，再选物品 1：

```text
总重量 = 1 + 2 = 3
总价值 = 6 + 10 = 16
剩余容量 = 2，放不下物品 2
```

但选择物品 1 和 2：

```text
总重量 = 2 + 3 = 5
总价值 = 10 + 12 = 22
```

所以：

```text
16 < 22
```

一个反例就足以否定该贪心规则对所有 0-1 背包实例都正确。[course_direct + editorial_inference | 基于 ev-004]

### 失败的根源

物品不可切分，选了一个单位价值较高的小物品后，可能留下无法利用的容量；局部比率并没有捕获不同物品之间的组合效应。[course_direct + editorial_inference | 基于 ev-004]

这不等于“所有背包问题都不能贪心”。课程此处只证明了该单位价值策略不能普遍解决 **0-1 背包**；不要把结论扩大到其他模型。[补充说明]

## 状态定义：两个参数缺一不可

课程定义：

```text
F(i,c) = 用物品 [0...i] 填充容量为 c 的背包时，能获得的最大价值
```

[course_direct + visual_direct | ev-005]

参数含义：

- `i`：当前允许使用的物品前缀终点；
- `c`：当前子问题可使用的容量；
- 返回值：满足容量限制的最大价值。

### `[0...i]` 是闭区间

它包含：

```text
0,1,...,i
```

共 `i+1` 件物品。若把它口误成“前 `i` 件”，就会让第 0 行、入口 `n-1` 和边界条件全部产生一位偏差。[补充说明]

### 为什么不能只记录 `i`

同样考虑到物品 `i` 时，剩余容量不同，可行选择与最优价值都可能不同；所以 `F(i,2)` 和 `F(i,5)` 不是同一个子问题。[editorial_inference]

### 为什么不能只记录 `c`

同样的容量下，可使用的物品集合不同，答案也可能不同；`F(0,c)` 与 `F(2,c)` 不能合并。[editorial_inference]

## 状态转移：选或不选第 `i` 件物品

对 `F(i,c)`，围绕第 `i` 件物品分类。

### 分支一：不选第 `i` 件

容量不变，可用物品只剩 `[0...i-1]`：

```text
F(i-1,c)
```

### 分支二：选择第 `i` 件

只有：

```text
c >= w[i]
```

时可行。选入后获得 `v[i]`，剩余容量为 `c-w[i]`，并且第 `i` 件不能再次使用，所以后续只能从 `[0...i-1]` 中选：

```text
v[i] + F(i-1,c-w[i])
```

### 合并

当 `c>=w[i]`：

```text
F(i,c) = max(F(i-1,c), v[i] + F(i-1,c-w[i]))
```

当 `c<w[i]`：

```text
F(i,c) = F(i-1,c)
```

[course_direct + visual_direct | formula-001, ev-005]

### 0-1 约束藏在哪个下标里

选择第 `i` 件后读取的是：

```text
F(i-1,c-w[i])
```

而不是：

```text
F(i,c-w[i])
```

前者把物品 `i` 从后续可选集合中移除；后者仍允许再次使用 `i`，会改变问题模型。[course_direct + editorial_inference | 基于 ev-005]

## 正确性：为什么两支足够

课程直接列出选与不选两支；下面把论证整理完整。

### 完备性

任一合法最优方案对第 `i` 件物品必然只有两种情况：不包含它，或包含它。不存在第三种可能，因为 0-1 约束不允许选择多次。[course_direct + editorial_inference | 基于 ev-003, ev-005]

### 两个子问题都正确缩小

- 不选 `i` 后，物品集合变成 `[0...i-1]`，容量仍为 `c`；
- 选 `i` 后，价值增加 `v[i]`，容量减少 `w[i]`，物品集合同样变成 `[0...i-1]`。

两支都严格减少 `i`，最终到达空物品前缀。[course_direct + visual_direct | ev-005, ev-006]

### 最优性

若固定了“选”或“不选”这一决定，剩余部分不用对应子问题的最优解，就能用更优子解替换，使原方案更优，产生矛盾。因此两支各自可以使用最优子问题值，再取较大者。[editorial_inference]

## 自顶向下：递归加二维记忆化

课程完整代码为：

```cpp
#include <iostream>
#include <vector>
#include <cassert>

using namespace std;

class Knapsack01{
private:
    vector<vector<int>> memo;

    // 用 [0...index] 的物品，填充容量为 c 的背包的最大价值
    int bestValue(const vector<int> &w, const vector<int> &v, int index, int c){
        if( index < 0 || c <= 0 )
            return 0;

        if( memo[index][c] != -1 )
            return memo[index][c];

        int res = bestValue(w, v, index - 1, c);
        if( c >= w[index] )
            res = max( res, v[index] + bestValue(w, v, index - 1, c - w[index]) );

        memo[index][c] = res;
        return res;
    }
public:
    int knapsack01(const vector<int> &w, const vector<int> &v, int C){
        int n = w.size();
        memo = vector<vector<int>>(n, vector<int>(C + 1, -1));
        return bestValue(w, v, n - 1, C);
    }
};
```

[visual_direct | code-001, ev-006]

### 递归契约

```text
bestValue(w,v,index,c)
= 只用 [0...index] 的物品、容量为 c 时的最大价值
```

这与数学状态 `F(index,c)` 完全对应。[course_direct + visual_direct | state-001, ev-005, ev-006]

### 执行顺序

1. `index<0`：没有物品可用，返回 0；
2. `c<=0`：没有正容量可用，返回 0；
3. `memo[index][c]!=-1`：直接返回缓存；
4. 先算不选当前物品的结果；
5. 若容量足够，再算选择当前物品的结果；
6. 取较大值并写回 `memo[index][c]`。

[course_direct + visual_direct | state-001, ev-006]

### 为什么缓存是 `n × (C+1)`

有效物品索引为：

```text
0...n-1
```

有效容量为：

```text
0...C
```

容量包含 0 和 C，共 `C+1` 个整数，所以列数不能只开 `C`。[course_direct + visual_direct | ev-006]

### 空输入怎样处理

当 `n==0`，缓存有 0 行，入口为：

```text
bestValue(...,-1,C)
```

函数先命中 `index<0` 并返回 0，不会访问 `memo[-1][C]`。[visual_direct + editorial_inference | code-001]

### 第 0 行初始化

只允许使用物品 0 时：

```text

memo[0][j] = v[0]   , j >= w[0]
```

```cpp
memo[0][j] = ( j >= w[0] ? v[0] : 0 );
```

即使 `j` 足以装入物品 0 多次，值也只能是一个 `v[0]`；这体现了 0-1 约束。[editorial_inference]

### 后续各行

```cpp

if( j >= w[i] )

```

每个格子都只依赖上一行：


## 自底向上完整代码

```cpp
#include <iostream>
#include <vector>
#include <cassert>

using namespace std;

class Knapsack01{
public:
    int knapsack01(const vector<int> &w, const vector<int> &v, int C){
        assert( w.size() == v.size() );
        int n = w.size();
        if( n == 0 )
            return 0;

        vector<vector<int>> memo(n, vector<int>(C + 1, -1));

        for( int j = 0 ; j <= C ; j ++ )
            memo[0][j] = ( j >= w[0] ? v[0] : 0 );

        for( int i = 1 ; i < n ; i ++ )
            for( int j = 0 ; j <= C ; j ++ ){
                memo[i][j] = memo[i-1][j];
                if( j >= w[i] )
                    memo[i][j] = max( memo[i][j], v[i] + memo[i-1][j - w[i]] );
            }

        return memo[n-1][C];
    }
};
```

[visual_direct | code-002, ev-008]

### 为什么先判断 `n==0`

下一步会访问：

```text
w[0]
memo[0][j]
memo[n-1][C]
```

空物品集合下这些索引都无效，因此必须先返回 0。[course_direct + visual_direct | ev-008]

### 为什么列循环包含 `C`

答案恰好位于容量 `C` 的列：

```text
memo[n-1][C]
```

所以循环是 `j<=C`，表的列数是 `C+1`。[course_direct + visual_direct | ev-008]

## 复杂度：课程直接结论与编辑推导分开

### 暴力枚举

```text
时间 O(n·2^n)
```

这是课程直接给出的结论。[course_direct | cx-001, ev-003]

### 自顶向下记忆化

有效缓存单元最多为：

```text
n * (C+1)
```

每个新状态只比较常数个分支，因此项目推导：

```text
时间 O(nC)
缓存空间 O(nC)
```

递归栈最深还可能为 `O(n)`；因为缓存表已经是 `O(nC)`，在通常 `C>=1` 的模型下总辅助空间仍由 `O(nC)` 主导。[editorial_inference | cx-002, cx-003]

### 自底向上二维表

外层遍历 `n` 行，内层遍历 `C+1` 列，每格常数工作：

```text
时间 O(nC)
辅助空间 O(nC)
```

[editorial_inference | cx-004, cx-005]

## 常见错误

1. **把 `[0...i]` 说成前 `i` 件**：实际有 `i+1` 件，会产生一位偏差。
2. **选择第 `i` 件后仍读取 `F(i,...)`**：会允许同一物品重复使用，破坏 0-1 约束。
3. **忘记检查 `c>=w[i]`**：会访问负容量或生成非法方案。
4. **缓存只按 `index` 建一维表**：同一物品前缀在不同容量下答案不同。
5. **列数只开 `C`**：索引 `C` 会越界，必须是 `C+1`。
6. **第 0 行按完全背包初始化**：物品 0 最多选一次，不能写成多个 `v[0]`。
7. **空输入仍初始化第 0 行**：会访问 `w[0]` 与 `memo[0]`。
8. **把贪心反例记成贪心算法答案**：16 是失败结果，最优值是 22。
9. **把 `O(nC)` 当课程明示**：当前证据只支持编辑推导。
10. **看到动态规划就说多项式时间**：`C` 是数值参数，应注意伪多项式边界。
11. **把 bottom-up 称作渐进更优**：本课两种 DP 都是 `O(nC)` 编辑推导，只是执行顺序不同。
12. **补 `<algorithm>` 后仍称逐字视频代码**：工程修复与画面转录必须分开。

前八项可由课程状态、代码和反例核对；后四项用于证据与复杂度边界。[course_direct + editorial_inference | ev-004–ev-008]

## 面试表达脚本

> “这是 0-1 背包，每件物品只能选零次或一次。我定义 `F(i,c)` 为只使用 `[0...i]` 的物品、容量为 `c` 时的最大价值。对第 `i` 件物品分类：不选得到 `F(i-1,c)`；若 `c>=w[i]`，选择得到 `v[i]+F(i-1,c-w[i])`，两者取最大。第二支使用 `i-1` 保证当前物品不再被选。可以用二维 memo 做自顶向下，也可以按行自底向上。根据状态数和每状态常数转移，两者时间为 `O(nC)`、当前二维空间为 `O(nC)`；这是从实现推导的伪多项式界。”

[course_direct + editorial_inference | 基于 ev-005–ev-008]

若被问为什么不用单位价值贪心，可立即给出课程反例：容量 5，物品 `(1,6),(2,10),(3,12)`；按比率选前两件得 16，但后两件得 22。[course_direct | ev-004]
