## 普通队列与优先队列

普通队列强调：

```text
先进入的元素先出去
```

优先队列强调：

```text
每次取出当前优先级最高的元素
```

课程举出的典型优先规则是“取最大值”或“取最小值”。[course_direct | ev-001]

因此，优先队列中的“队首”不是由进入时间唯一决定，而是由比较规则决定；相同优先级元素的相对顺序还需要额外规则，否则不能假设稳定。[course_direct + editorial_inference | 基于 ev-001, ev-006]

### 比较器方向

本课最终规则：

```cpp
return a % 10 > b % 10;
```

让个位数较小的元素拥有更高的出队优先级，所以课程现场输出的个位数按非递减顺序出现。[course_direct + visual_direct | ev-006]

可以用两个数做心算：

```text

a % 10 = 3
b % 10 = 8

myCmp(23, 48) 返回 false
myCmp(48, 23) 返回 true
```

在该比较规则下，个位数 3 比个位数 8 更早到达 `top()`。[editorial_inference | 基于 ev-006]


```cpp
#include <iostream>
#include <queue>
#include <ctime>

using namespace std;

bool myCmp( int a, int b ){
    return a%10 > b%10;
}

int main() {
    srand( time(NULL) );

    // 默认情况下，最大堆
    priority_queue<int> pq;
    for( int i = 0 ; i < 10 ; i ++ ){
        int num = rand()%100;
        pq.push( num );
        cout<<"insert "<<num<<" in priority queue."<<endl;
    }

    while( !pq.empty() ){
        cout<<pq.top()<<" ";
        pq.pop();
    }
    cout<<endl<<endl;

    // 底层是最小堆
    priority_queue<int, vector<int>, greater<int>> pq2;
    for( int i = 0 ; i < 10 ; i ++ ){
        int num = rand()%100;
        pq2.push( num );
        cout<<"insert "<<num<<" in priority queue."<<endl;
    }

    while( !pq2.empty() ){
        cout<<pq2.top()<<" ";
        pq2.pop();
    }
    cout<<endl<<endl;

    // 使用自定义Comparator的priority queue
    priority_queue<int, vector<int>, function<bool(int,int)>> pq3(myCmp);
    for( int i = 0 ; i < 10 ; i ++ ){
        int num = rand()%100;
        pq3.push( num );
        cout<<"insert "<<num<<" in priority queue."<<endl;
    }

    while( !pq3.empty() ){
        cout<<pq3.top()<<" ";
        pq3.pop();
    }
    cout<<endl<<endl;

    return 0;
}
```

## 常见易错点

### 把默认方向记反

```cpp
priority_queue<int>
```

默认是最大堆，不是最小堆。[course_direct + visual_direct | ev-004]

### 只写比较器、不写底层容器

要自定义第三个模板参数时，仍需显式给出第二个参数：

```cpp

```

[course_direct + visual_direct | ev-005, ev-006]

### 把自定义 `>` 抄成 `<`

本课最终代码是：

```cpp
return a % 10 > b % 10;
```

写成 `<` 会反转个位数优先方向，与最终课程画面和输出不一致。[visual_direct + editorial_inference | 基于 ev-006]

### 对相同优先键假设稳定

比较器只看 `% 10`，没有用原值或入队序号打破平局，因此不应依赖相同个位数元素的相对次序。[editorial_inference | 基于 ev-006]

### 忘记空队列门禁

屏幕循环总是在：

```cpp

```

内部读取 `top()` 和执行 `pop()`。不要在空队列上访问 `top()`。[visual_direct + editorial_inference | 基于 ev-004–ev-006]
