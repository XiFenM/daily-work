## 从等分到 0-1 背包

若：

```text
sum = nums[0] + nums[1] + ... + nums[n-1]
C = sum / 2
```

那么原问题等价于：

> 是否能从 `nums` 中选择若干数字，每个数字最多选择一次，使被选数字之和恰好为 `C`？

[course_direct + visual_direct | ev-002]

若找到这样一个子集，它的补集和为：

```text
sum - C = sum - sum/2 = sum/2 = C
```

所以两部分等和。反过来，任何等和划分中的任意一半就是一个能装满 `C` 的子集。[course_direct + editorial_inference | ev-002]

这里没有价值最大化，只有“能否恰好达到容量”，所以状态值是布尔值。

## 状态定义与递推

课程幻灯片写作：

```text
F(n, C)：考虑 n 个物品，能否填满容量 C

F(i, c) = F(i-1, c) || F(i-1, c-w(i))
```

[course_direct + visual_direct | ev-002]

两支分别是：

- **不选第 `i` 个数字**：目标容量仍为 `c`；
- **选择第 `i` 个数字**：目标容量减少 `w(i)`；
- 只要任一分支可行，当前状态就可行。[course_direct | ev-002]

代码使用索引口径：

```text
tryPartition(nums, index, target)
= 只允许使用 nums[0...index] 时，能否凑出 target
```

因此公式与代码虽然符号略不同，决策结构一致。[visual_direct + editorial_inference | ev-002, ev-004]

## 方案一：记忆化搜索

### 三态缓存

```text
memo[index][target] = -1  未计算
memo[index][target] =  0  不可达
memo[index][target] =  1  可达
```

若直接使用 `bool`，`false` 无法同时表示“尚未计算”和“已经计算且不可达”；因此课程使用 `int`。[course_direct + visual_direct | ev-004]

### 递归终止

```cpp
if (sum == 0)
    return true;
if (sum < 0 || index < 0)
    return false;
```

[course_direct + visual_direct | ev-004]

先判断 `sum==0` 很重要：即使此时 `index<0`，已经恰好凑满也应返回 `true`。[editorial_inference | 基于 code-001]

### 转移

```cpp
memo[index][sum] =
    (tryPartition(nums, index - 1, sum) ||
     tryPartition(nums, index - 1, sum - nums[index])) ? 1 : 0;
```

[course_direct + visual_direct | ev-004]

两个递归分支都把 `index` 减一，所以同一个数字不会再次进入更深层状态，0-1 约束自然成立。[editorial_inference | 基于 code-001]

### 视频核心代码

```cpp
class Solution {
private:
    vector<vector<int>> memo;

    bool tryPartition(const vector<int>& nums, int index, int sum) {
        if (sum == 0)
            return true;
        if (sum < 0 || index < 0)
            return false;
        if (memo[index][sum] != -1)
            return memo[index][sum] == 1;

        memo[index][sum] =
            (tryPartition(nums, index - 1, sum) ||
             tryPartition(nums, index - 1, sum - nums[index])) ? 1 : 0;
        return memo[index][sum] == 1;
    }
public:
    bool canPartition(vector<int>& nums) {
        int sum = 0;
        for (int i = 0; i < nums.size(); i++) {
            assert(nums[i] > 0);
            sum += nums[i];
        }
        if (sum % 2 != 0)
            return false;

        memo = vector<vector<int>>(
            nums.size(), vector<int>(sum / 2 + 1, -1));
        return tryPartition(nums, nums.size() - 1, sum / 2);
    }
};
```

## 方案二：一维自底向上 DP

课程使用：

```cpp
vector<bool> memo(C + 1, false);

for (int j = 0; j <= C; j++)
    memo[j] = (nums[0] == j);

for (int i = 1; i < n; i++)
    for (int j = C; j >= nums[i]; j--)
        memo[j] = memo[j] || memo[j - nums[i]];
```

[course_direct + visual_direct | ev-005]

### 为什么容量必须倒序

处理 `nums[i]` 时，右侧容量先更新：

```text
j = C, C-1, ..., nums[i]
```

因此读取 `memo[j-nums[i]]` 时，较小下标尚未在本轮被更新，仍保存上一轮状态。当前数字只会被加入一次。[editorial_inference | 基于 ev-005]

若改成正序：

```text
j = nums[i], nums[i]+1, ..., C
```

那么较小容量可能刚刚使用过 `nums[i]`，更大容量再次读取它就会把同一件物品重复计算，语义变成完全背包。[course_direct + editorial_inference | ev-005]

### 课程初始化的特殊边界

通常的通用 subset-sum 模板写作：

```cpp
memo[0] = true;
```

表示空集可以凑出 0。课程代码却写：

```cpp
memo[j] = (nums[0] == j);
```

因为题目保证正整数，所以 `memo[0]` 为 `false`。这意味着课程数组实际追踪的是：

> 当前前缀中，**包含 `nums[0]`** 的某个子集能否凑出 `j`。

[visual_direct + editorial_inference | ev-001, ev-005]

它对本题最终判断仍然正确：若存在等分方案，两半中必有且只有一半包含 `nums[0]`，那一半的和仍为 `C`，所以受限 DP 一定能找到它。[editorial_inference]

但这段初始化不能无条件搬到“任意目标 subset-sum”题中。若要写可复用模板，优先使用：

```cpp
vector<bool> memo(C + 1, false);
memo[0] = true;
for (int value : nums)
    for (int j = C; j >= value; --j)
        memo[j] = memo[j] || memo[j - value];
```

### 视频核心代码

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int sum = 0;
        for (int i = 0; i < nums.size(); i++) {
            assert(nums[i] > 0);
            sum += nums[i];
        }
        if (sum % 2 != 0)
            return false;

        int n = nums.size();
        int C = sum / 2;
        vector<bool> memo(C + 1, false);

        for (int i = 0; i <= C; i++)
            memo[i] = (nums[0] == i);

        for (int i = 1; i < n; i++)
            for (int j = C; j >= nums[i]; j--)
                memo[j] = memo[j] || memo[j - nums[i]];

        return memo[C];
    }
};
```

## 正确性骨架

### 建模等价性

存在总和为 `C` 的子集，当且仅当其补集总和也为 `C`，所以背包可达性与等和划分等价。[course_direct + editorial_inference | ev-002]

### 记忆化递推

任何合法子集对当前数字只有两类：不含它，或含它。递推两支互不遗漏；索引递减保证每个数字最多使用一次。[editorial_inference | 基于 ev-002, ev-004]

### 一维递推

初始化建立首元素状态；每轮用“不选当前数字”的旧 `memo[j]` 与“选择当前数字”的旧 `memo[j-value]` 作逻辑或。倒序保证两项都来自上一轮语义。[editorial_inference | 基于 ev-005]

## 高频错误

1. 总和为奇数仍进入 DP；
2. 把“恰好装满”写成“不超过容量”；
3. 一维 0-1 背包容量正序更新，导致同一数字重复使用；
4. 忘记区分缓存的“未计算”和 `false`；
5. 直接访问 `nums[0]` 却忽略接口是否允许空数组；
6. 把课程首元素初始化当作通用 subset-sum 模板；
7. 把 `O(n*sum)` 误说成只依赖输入长度的多项式复杂度；
8. 把课程的百万级估算写成严格的最坏上界计算。[course_direct + editorial_inference]

当输入数值按标准二进制编码时，`sum` 可能相对输入位数指数增长，因此 `O(n*sum)` 通常称为伪多项式时间；这是补充复杂度分类，不是课程原话。[补充说明]

## 面试回答模板

1. **确认约束**：非空、正整数、每个元素只能使用一次；
2. **做奇偶剪枝**：总和为奇数立即返回 `false`；
3. **完成建模**：目标容量 `C=sum/2`，求是否存在恰好填满的 0-1 子集；
4. **定义状态**：二维 `dp[i][c]` 或一维 `dp[c]`；
5. **写转移**：`dp[c] = dp[c] || dp[c-value]`；
6. **强调倒序**：维护上一轮语义，避免重复使用当前元素；
7. **给复杂度**：`O(n*C)` 时间，一维实现 `O(C)` 辅助空间；
8. **补边界**：通用模板初始化 `dp[0]=true`；若照课程首行初始化，要说明其本题特定正确性。[editorial_inference]
