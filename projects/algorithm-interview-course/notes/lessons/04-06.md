## 一句话结论

固定每个点 `i` 作为枢纽，遍历所有 `j != i`，用：

```text
record[distanceSquared(i,j)] += 1
```

统计每个距离平方的频次。若某个桶的频次为 `m`，则先选有序三元组中的 `j` 有 `m` 种，再选不同的 `k` 有 `m-1` 种，所以该桶贡献：

```text
m * (m - 1)
```

把所有枢纽、所有距离桶的贡献累加，即得到全部 Boomerang。课程口径下时间 `O(n²)`、辅助空间 `O(n)`。[视频 00:01:33–00:12:11；ev-002、ev-003、ev-004]

## 基线：三重循环暴力枚举

### 直接思路

最直接的方法是枚举：

```text
每个 i
  每个 j != i
    每个 k != i 且 k != j
      检查 distance(i,j) == distance(i,k)
```

三层枚举使时间复杂度为：

```text
O(n³)
```

若只保存循环索引和计数器，辅助空间可整理为 `O(1)`；这个空间结论来自暴力实现形态，不是视频本段的独立复杂度结论。[整理推导]


固定某个 `i` 后，暴力法会为每个 `j` 再重新枚举全部 `k`。但判断条件只关心：

## 优化关键一：固定枢纽 `i`

### 为什么固定的是第一个点

题目条件：

```text

```

共享的参照点是 `i`。固定 `i` 后，所有其余点只需要计算一次“到 `i` 的距离”，问题就转化为：

> 对当前 `i`，每一种距离出现了多少次？

[视频 00:01:33–00:05:17；ev-002]

如果固定的是 `j` 或 `k`，却仍要比较它们分别到变化中的 `i` 的距离，就没有直接把共享变量消除。选择枢纽不是任意命名，而是由等式中共同出现的点决定。[整理推导]

### 每个枢纽独立建表

对当前 `i`：

```text
record[d] = 到 i 的距离平方为 d 的其他点数量
```

处理下一个枢纽时，需要重新创建空表，因为同一对坐标相对于不同枢纽的距离分组一般不同。[视频 00:01:33–00:11:17；ev-002、ev-003]

## 优化关键二：用距离平方作 key

### 欧氏距离与距离平方

两点：

```text
pa = (xa, ya)
pb = (xb, yb)
```

欧氏距离是：

```text
sqrt((xa-xb)² + (ya-yb)²)
```

屏幕辅助函数返回的是：

```text
(xa-xb)² + (ya-yb)²
```

即距离平方。[视频 00:05:17–00:11:17；ev-003] [人工 QA 关键画面 09:20]

### 为什么不需要开根号

平方根函数在非负数上严格单调，因此：

```text
sqrt(a) == sqrt(b)  <=>  a == b
```

对于距离判断：

```text
distance(i,j) == distance(i,k)
```

与：

```text
distanceSquared(i,j) == distanceSquared(i,k)
```

完全等价。[视频 00:05:17–00:11:17；ev-003] [整理推导]

不开根号带来两个直接好处：

1. 不需要把整数坐标转换成浮点距离，避免浮点表示和相等比较误差；
2. 可以直接用整数距离平方作为 `unordered_map` 的 key。[视频 00:05:17–00:11:17；ev-003]

课程重点是正确、稳定的相等判定；本文不额外把“少一次 `sqrt`”夸大为决定整体复杂度的因素。无论是否开根号，外层枚举次数仍决定渐进复杂度。[补充说明]

## 优化关键三：为什么贡献是 `m*(m-1)`

### 有序选择

设固定枢纽为 `i`，某个距离平方桶里有 `m` 个点。要构成 `(i,j,k)`：

1. `j` 可以从这 `m` 个点中任选，计 `m` 种；
2. `k` 必须和 `j` 不同，所以剩 `m-1` 种。

根据乘法原理：

```text
m * (m - 1)
```

[视频 00:01:33–00:11:17；ev-002、ev-003]

### 为什么不是 `C(m,2)`

无序组合数：

```text
C(m,2) = m*(m-1)/2
```

只把 `{j,k}` 视为一个没有方向的点对。但题目统计有序三元组：

```text
(i,j,k)
(i,k,j)
```

是两个不同结果。每个无序点对对应两种顺序，所以：

```text
2 * C(m,2) = m*(m-1)
```

[视频 00:00:00–00:11:17；ev-001、ev-002、ev-003] [整理推导]

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>

using namespace std;

// 时间复杂度: O(n^2)
class Solution {
public:
    int numberOfBoomerangs(vector<pair<int, int>>& points) {

        int res = 0;
        for (int i = 0; i < points.size(); i++) {

            unordered_map<int, int> record;
            for (int j = 0; j < points.size(); j++)
                if (j != i)
                    record[dis(points[i], points[j])]++;

            for (unordered_map<int, int>::iterator iter = record.begin();
                 iter != record.end(); iter++)
                if (iter->second >= 2)
                    res += (iter->second) * (iter->second - 1);
        }

        return res;
    }

private:
    int dis(const pair<int, int>& pa, const pair<int, int>& pb) {
        return (pa.first - pb.first) * (pa.first - pb.first) +
               (pa.second - pb.second) * (pa.second - pb.second);
    }
};
```

```cpp

    unordered_map<int, int> record;
    // ...
}
```

`record` 的含义依赖当前枢纽 `i`。把它声明在外层循环内部，既保证新枢纽从空表开始，也让上一轮的键和值不污染下一轮。[视频 00:05:17–00:11:17；ev-003]

### 为什么跳过 `j == i`

若把枢纽自身加入表，会额外得到距离平方 0 的一个点，但它不能作为题目中与 `i` 不同的另一个点。屏幕代码显式使用：

```cpp
if (j != i)
```

## 纸面推演

### 样例：三个共线点

```text
p0 = (0,0)
```


固定 `p2`：

```text

```

### 一个频次为 3 的桶

```text

(i,b,a)  (i,b,c)
(i,c,a)  (i,c,b)
```

一共 `3*2=6` 个，而不是 `C(3,2)=3` 个。[视频 00:01:33–00:05:17；ev-002] [整理推导]

## 正确性解释

课程直接给出按枢纽分组和 `m*(m-1)` 的计数逻辑；以下按覆盖性、合法性和唯一性进行编辑性整理，不是讲师逐字形式化证明。[视频 00:01:33–00:11:17；ev-002、ev-003] [整理推导]

### 1. 每个合法三元组都会被计入

任取合法三元组 `(i,j,k)`。当外层循环处理其第一个点 `i` 时：

- `j != i`，所以 `j` 被写入 `record`；
- `k != i`，所以 `k` 被写入 `record`；
- 因为 `distance(i,j) == distance(i,k)`，两者的距离平方相等，进入同一个桶。

该桶的有序点对枚举包含 `(j,k)`，所以这个三元组会被计入。[整理推导]

### 2. 每个被计入的结果都合法

某个桶只包含到当前 `i` 距离平方相同的点。`m*(m-1)` 选择两个不同点作为有序 `(j,k)`，因此：

```text
j != k
distance(i,j) == distance(i,k)
```

并且建表时已经排除了 `j == i`；被选作 `k` 的点同样来自这些“非 `i`”点。由此形成的三元组满足题意。[视频 00:05:17–00:11:17；ev-003] [整理推导]

### 3. 不会重复计数同一个有序三元组

有序三元组 `(i,j,k)` 的第一个点唯一决定它在哪一轮外层循环被处理；距离平方唯一决定它属于当前 `i` 的哪个桶；桶内有序点对 `(j,k)` 也唯一。因此同一有序三元组只被计入一次。[整理推导]

### 4. 终止

外层遍历有限的 `n` 个枢纽；每个枢纽的建表循环遍历有限的 `n` 个点，汇总循环遍历有限的距离键。所有循环最终结束，返回累计值 `res`。[整理推导]

## 复杂度分析

### 时间复杂度

对每个固定的 `i`：

1. 遍历全部 `j`，执行至多 `n-1` 次距离计算和哈希频次更新，数量级 `O(n)`；
2. `record` 最多有 `n-1` 个不同距离键，遍历所有键汇总贡献，数量级 `O(n)`。

因此单个枢纽为：

```text
O(n) + O(n) = O(n)
```

一共有 `n` 个枢纽：

```text
n * O(n) = O(n²)
```

[视频 00:11:17–00:12:11；ev-004]

这是课程使用 `unordered_map` 的口径。频次更新通常按均摊 `O(1)` 计算；本课没有给出哈希退化情况下的独立最坏时间界。[补充说明]

### 辅助空间复杂度

固定 `i` 时，`record` 最多保存 `n-1` 个不同距离平方：

```text
O(n)
```

处理下一个 `i` 时，上一轮局部表被释放并重新建立；同时存在的表仍只有一张，所以空间不会乘上外层的 `n`。[视频 00:05:17–00:12:11；ev-003、ev-004]

课程结论是：

```text
时间 O(n²)
空间 O(n)
```

[视频 00:11:17–00:12:11；ev-004]

### 与暴力方案对照

| 方案             | 核心操作                            | 时间    | 辅助空间          |
| ---------------- | ----------------------------------- | ------- | ----------------- |
| 三重循环         | 显式枚举每个 `(i,j,k)`              | `O(n³)` | `O(1)` 为整理推导 |
| 固定枢纽加查找表 | 对每个 `i` 统计距离频次，再按桶计数 | `O(n²)` | `O(n)`            |

[视频 00:01:33–00:12:11；ev-002、ev-003、ev-004]

优化本质是用 `O(n)` 的局部频次表，把对 `(j,k)` 的显式二重枚举变成一次分桶和公式计数。[整理推导]

## 整型溢出核算

### 课程明确检查的是距离平方

屏幕代码使用 `int` 返回：

```text
dx² + dy²
```

课程提醒，写出平方表达式后不能自动假设 `int` 安全，必须回到坐标范围核算。[视频 00:12:11–00:13:38；ev-005]

题目给出每个坐标分量：

```text
-10000 <= coordinate <= 10000
```

所以任意两个点的单轴坐标差绝对值最多为：

```text
10000 - (-10000) = 20000
```

单轴平方最多：

```text
20000² = 400,000,000
```

二维距离平方最多：

```text
20000² + 20000²
= 400,000,000 + 400,000,000
= 800,000,000
= 8 * 10^8
```

[视频 00:12:11–00:13:38；ev-005]

课程按 32 位有符号 `int` 上界：

```text
2³¹ - 1 = 2,147,483,647
```

进行比较：

```text
800,000,000 < 2,147,483,647
```

因此在本题课程给定坐标范围、且 `int` 为 32 位有符号整数的口径下，屏幕 `dis` 表达式的最大非负结果不会溢出。[视频 00:12:11–00:13:38；ev-005]

### 为什么必须在乘法前确认类型

C++ 中表达式：

```cpp
(pa.first - pb.first) * (pa.first - pb.first)
```

先按操作数类型完成乘法，再赋给返回值。即使后来把返回类型改成更宽类型，若操作数仍是 `int` 且范围更大，乘法也可能在提升前溢出。更通用的写法会先把差值提升到 `long long`；但本课坐标范围已经使当前 32 位 `int` 计算安全，视频没有展示宽类型版本。[视频 00:12:11–00:13:38；ev-005] [补充说明]

### `res` 的额外上界检查

视频这一段明确讲的是距离平方键的溢出。作为代码审查补充，可由 `n <= 500` 给 `res` 一个宽松组合上界：每个枢纽至多有 `n-1` 个其他点全部处于同一距离桶，贡献 `(n-1)(n-2)`；所有枢纽合计不超过：

```text
n(n-1)(n-2)
<= 500 * 499 * 498
= 124,251,000
```

这个上界也小于 `2³¹-1`。它只说明课程约束下计数器的组合上界可装入常见 32 位有符号 `int`，不是视频直接给出的计算，也不证明所有这类几何题都能继续使用 `int`。[整理推导]

### 迁移到其他题目时重新核算

若坐标范围扩大到绝对值 `10^9`，或坐标改为浮点数，当前 key 类型与计算方式都需要重新设计。课程把这个检查迁移到下一道直线题作为面试提醒：先问范围和表示，再决定整数宽度、浮点策略或规范化方式。[视频 00:12:11–00:14:45.6；ev-005、ev-006]

## 边界条件与常见错误

### 边界条件

1. **少于三个点**：无法形成三个不同位置的三元组，屏幕循环会得到 0；这是根据代码状态推导，结构化题面没有单列该边界。[视频 00:05:17–00:11:17；ev-003] [整理推导]
2. **所有距离都不同**：每个桶频次均为 1，`if (m >= 2)` 不进入，当前枢纽贡献 0。[视频 00:05:17–00:11:17；ev-003]
3. **多个点等距**：频次必须完整累计；同一距离桶用 `m*(m-1)` 一次性加入全部有序点对。[视频 00:01:33–00:11:17；ev-002、ev-003]
4. **枢纽自身**：必须跳过 `j == i`，不能把距离 0 的自身放进表。[视频 00:05:17–00:11:17；ev-003]
5. **重复坐标**：课程证据没有说明是否允许，也没有讨论不同索引但同坐标的语义；面试中应依据题面确认，不在本文擅自裁决。[补充说明]
6. **哈希遍历顺序**：`unordered_map` 不保证键的顺序，但这里只求各桶贡献之和，遍历顺序不影响结果。[补充说明]

### 常见错误

- 仍然三重枚举所有 `(i,j,k)`，没有利用固定 `i` 后可以按距离分组的结构。[视频 00:01:33–00:05:17；ev-002]
- 把全局点对距离作为 key，却没有把枢纽 `i` 纳入状态；同一个距离在不同枢纽下不能混成一张频次表。[视频 00:01:33–00:11:17；ev-002、ev-003] [整理推导]
- 用真实距离的浮点数作 key，并直接做浮点相等比较。[视频 00:05:17–00:11:17；ev-003]
- 使用距离平方，却没有先根据坐标范围检查乘法和加法是否溢出。[视频 00:12:11–00:13:38；ev-005]
- 用 `unordered_set` 只记录距离存在性，丢失同距点数量。[视频 00:01:33–00:11:17；ev-002、ev-003] [整理推导]
- 把桶贡献写成 `C(m,2)` 或 `m*(m-1)/2`，忽略 `(i,j,k)` 与 `(i,k,j)` 是两个结果。[视频 00:00:00–00:11:17；ev-001、ev-002、ev-003]
- 把贡献写成 `m²`，错误允许 `j == k`。[视频 00:01:33–00:11:17；ev-002、ev-003] [整理推导]
- 忘记跳过 `j == i`，把枢纽自身放进距离 0 桶。[视频 00:05:17–00:11:17；ev-003]
- 在外层循环之外复用 `record` 却不清空，使不同枢纽的距离频次相互污染。[视频 00:05:17–00:11:17；ev-003] [整理推导]
- 展示 normalized 中省略 `if (iter->second >= 2)` 的片段，却声称它是视频原码的完整精确转录。[人工 QA 校正]
