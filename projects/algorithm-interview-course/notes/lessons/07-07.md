## 题目：BST 的最近公共祖先

最近公共祖先可以理解为：

> 同时是 `p` 与 `q` 祖先、并且在满足该条件的节点中离二者最近的节点；节点也可以是自己的祖先。[course_direct + visual_direct | ev-003 | 视频 04:38–06:14]

课程示例 BST 的核心结构为：

```text
        6
      /   \
     2     8
    / \   / \
   0   4 7   9
      / \
     3   5
```

- `p = 2`、`q = 8` 时，最近公共祖先为 `6`；
- `p = 2`、`q = 4` 时，最近公共祖先为 `2`，因为节点可以是自己的祖先。[course_direct + visual_direct | ev-003 | 视频 04:38–06:14]

## 三分支决策

令当前节点为 `root`。

### 分支一：两者都小于当前根

若：

```text
p->val < root->val
q->val < root->val
```

根据 BST 的整棵子树有序性，`p`、`q` 都在左子树；它们的最近公共祖先也必在左子树，于是递归到 `root->left`。[course_direct + visual_direct | ev-004, ev-005 | 视频 06:14–13:10]

### 分支二：两者都大于当前根

若：

```text
p->val > root->val
q->val > root->val
```

两者都在右子树，递归到 `root->right`。[course_direct + visual_direct | ev-004, ev-005 | 视频 06:14–13:10]

### 分支三：其余情况

其余情况包括：

- `p`、`q` 分居当前根两侧；
- 当前根就是 `p`；
- 当前根就是 `q`。[course_direct + visual_direct | ev-004, ev-005 | 视频 06:14–13:10]

在这些情况下，当前根就是第一个使两条搜索路径分叉的节点，或已经命中其中一个目标，因此直接返回 `root`。[course_direct + visual_direct | ev-004, ev-005 | 视频 06:14–13:10]

## 完整课程代码

```cpp
#include <iostream>
#include <cassert>

using namespace std;

/// Definition for a binary tree node.
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        assert(p != NULL && q != NULL);
        if (root == NULL)
            return NULL;

        if (p->val < root->val && q->val < root->val)
            return lowestCommonAncestor(root->left, p, q);
        if (p->val > root->val && q->val > root->val)
            return lowestCommonAncestor(root->right, p, q);

        return root;
    }
};
```

## 状态、递归契约与终止

### 递归契约

> 在以 `root` 为根的 BST 中，且 `p`、`q` 非空并存在于该树内时，`lowestCommonAncestor(root, p, q)` 返回二者的最近公共祖先。[course_direct + editorial_inference | 基于 ev-004, ev-005 与 code-001]

### 状态变化

- 每次递归只把 `root` 更新为左孩子或右孩子；
- `p`、`q` 始终保持不变；
- 搜索区间严格缩小为一棵子树。[editorial_inference | 基于 code-001]

### 终止

- 如果 `root == NULL`，返回 `NULL`；
- 如果两者不再同处一侧，返回当前 `root`；
- 在目标存在的前提下，递归沿一条搜索路径推进，最终会到达分叉点或其中一个目标。[course_direct + visual_direct | ev-005] [editorial_inference | 终止性说明]

## 正确性证明

对当前根 `root` 分情况：

1. **`p`、`q` 都小于根值**：BST 性质保证两者都在左子树。任何同时为二者祖先且比 `root` 更近的候选只能位于左子树，递归左侧不丢答案。
2. **`p`、`q` 都大于根值**：同理，答案只能在右子树。
3. **其他情况**：两者分居两侧时，任何严格位于某一侧的节点都不可能同时成为二者祖先；若当前根等于其中一个目标，该目标本身就是包含另一个目标的最低祖先。因此当前根是 LCA。[editorial_inference | 基于 ev-001、ev-004、ev-005]

三个分支覆盖所有比较结果，且前两个条件互斥；代码顺序与证明一致。[editorial_inference | 基于 code-001]

## 复杂度

本题代码每次只进入一棵子树，不会同时遍历左右两侧。设树高为 `h`：

- 时间复杂度：`O(h)`；
- 递归调用栈：`O(h)`；
- 平衡树中 `h = O(log n)`，因此时间与栈均为 `O(log n)`；
- 倾斜树中 `h = O(n)`，最坏时间与栈均为 `O(n)`。[editorial_inference | 基于 code-001]

这些是对 LCA 代码的编辑推导。课程在 `ev-002` 直接讲的是 BST 基本操作通常为 `O(log n)`，两类结论不能混写成同一句课程原话。
