# 单节笔记复核任务

你将收到课程定位、视频或可回看的关键片段、模型原始响应和一份单节草稿。请做证据导向的复核，不要只润色文字。

## 输入定位

- 节次：`{{lesson_id}} {{lesson_title}}`
- 实际时长：`{{actual_duration}}`

## 复核顺序

1. 确认视频、节次 ID 和标题没有错配。
2. 检查所有时间戳是否在实际时长内，并抽查关键结论是否能在对应位置找到。
3. 检查问题条件、变量定义、算法步骤、正确性和复杂度是否互相一致。
4. 检查是否把分析者常识写成讲师原意，或仅根据大纲标题补写内容。
5. 检查伪代码的边界、索引、终止条件和最小反例。
6. 按 `inputs/relation-model.json` 检查关系候选；证据不足则降级或删除。
7. 保留所有真实不确定项，不要为追求完整而猜测。

## 输出

先输出复核结论：

- `pass`：可以标记为 `reviewed`；
- `revise`：列出可直接修正的问题；
- `recheck_video`：列出必须回看视频的时间段和原因。

然后给出：

1. 事实问题清单；
2. 结构或表达问题清单；
3. 关系候选处理清单；
4. 修订后的完整 Markdown 笔记。

修订后的 front matter 中将 `analysisStatus` 改为 `reviewed`，只有证据复核通过时才能这样做。
