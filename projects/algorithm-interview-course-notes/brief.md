# 算法面试视频课程笔记项目简报

## 目标

- 为课程大纲中的每一节视频产出可独立复习的中文详细笔记。
- 保留重要推导、代码思路、正确性依据、复杂度条件、面试沟通方法和时间戳证据。
- 在单节笔记之上形成章节总结、全课知识地图和有证据的跨视频联系。
- 让后续补传、重跑、模型升级和人工修订都可追踪，不把结果绑定到一次性对话。

## 受众与用途

- 主要受众：准备算法面试、希望系统复习常见题型的学习者。
- 主要用途：本地检索、按章节复习、题型对照和面试前查漏补缺。
- 输出语言：简体中文；算法、数据结构、LeetCode 题名等保留常用英文。
- 发布平台：暂无；本项目默认不上传或发布课程视频及其内容。

## 输入

- 课程目录：`inputs/course-outline.json`
- 原始视频建议目录：`work/algorithm-interview-course-notes/source-videos/`
- 视频属于用户提供的私有输入，不提交到 Git。
- 每次分析前先用 FFprobe 记录实际时长、编码、分辨率和音轨，再决定是否创建理解用压缩副本。

## 笔记原则

- 讲师明确表达的内容、从画面或代码直接观察到的内容、分析者推导的内容必须分开标注。
- 不用课程标题或常识替代实际视频内容；听不清、看不清或无法确认时明确写入“不确定项”。
- 不制作逐字稿，不大段复刻受版权保护的课程原文；使用结构化归纳、必要的短语和自行组织的伪代码。
- 每个关键算法结论尽量附视频时间戳；跨视频关系必须附两端证据或标注为仅来自大纲。
- 复杂度必须写清输入规模、采用的数据结构及隐藏条件，不能只给孤立的 Big O。
- 代码内容重点保留变量语义、循环不变量、边界、终止条件和测试用例，而非机械抄屏。

## 验收标准

- 每份已确认课程内容恰好对应一份单节笔记，无漏项、错配或重复。
- 每份笔记包含摘要、目标、时间线、详细内容、复杂度、正确性、面试要点、易错点、练习与不确定项。
- 涉及具体题目时，记录问题定义、约束、解法演进、关键不变量、复杂度和边界测试。
- 章节综合只引用已完成的单节笔记；全课综合只引用已完成的章节与单节笔记。
- 知识图谱中的每条语义关系带来源类型、证据位置和置信度。
- 处理记录包含模型、参数、请求 ID、输入与输出路径；不包含 API key 或大段 base64。
