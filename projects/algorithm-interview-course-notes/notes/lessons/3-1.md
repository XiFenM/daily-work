# 3-1 从二分查找法看如何写出正确的程序

## 一句话定位

本节以有序数组的二分查找为例，讲解如何通过明确变量语义（前闭后闭区间）与维护“循环不变量”（Loop Invariant）来写出边界严格正确的算法代码。

## 学习目标

- 掌握基于闭区间 `[l...r]` 语义的二分查找算法实现细节。
- 理解“循环不变量”概念，并能解释 `l <= r`、`l = mid + 1` 与 `r = mid - 1` 的边界推导依据。
- 能够编写针对二分查找的自动化测试用例（断言与计时测试）。

## 详细笔记

### 1. 数组问题在算法中的地位 (`00:00`)

- **讲师明确说明**：数组是面试中最常见的数据结构。很多复杂问题本质上都是在数组中进行操作。
- **画面直接可见**（课件展示）：
  - **排序算法**：选择排序、插入排序、归并排序、快速排序等均基于数组。
  - **查找算法**：二分查找法基于有序数组。
  - **底层依赖数组的数据结构**：栈（Stack）、队列（Queue）、堆（Heap/优先队列）以及动态数组。

### 2. 为什么写出正确的程序很难 (`01:40`)

- **讲师明确说明**：很多算法思想极其直观（如快速排序、堆、二分查找），用自然语言表述很容易，但落实到具体代码时，往往需要处理大量的索引（Index）和边界边界条件。
- **历史事实**（课件展示）：二分查找的思想在 **1946年** 被提出，但第一个完全没有 Bug 的二分查找程序直到 **1962年** 才被实现，前后历经 16 年。
- **示例选择理由**：二分查找难度介于“求数组最大最小值”（太简单）与“快速排序”（较复杂）之间，是体会“如何写出正确程序”的最佳示例。

### 3. 二分查找的思想与实现步骤 (`03:30–11:48`)

```
  [                  V                  ]  <- 有序数组
                     ^ (mid)
  < V                V                 > V
 [      ]                             [      ]
```

- **算法基础前提**：数据必须是**有序数组**。
- **明确变量语义** (`05:00`)：
  - 声明边界变量 `int l = 0, r = n - 1;`。
  - **讲师强调**：在此定义下，`l` 与 `r` 的语义为 **在 `[l...r]` 的前闭后闭区间内寻找 target**。
- **推导循环判定条件** (`07:41`)：
  - 条件写为 `while (l <= r)`。
  - **正确性依据**：当 `l == r` 时，区间 `[l...r]` 依然包含 1 个有效元素（即 `[l...l]`），此时搜索区间有效，必须继续进入循环检查。
- **推导区间收缩逻辑** (`08:55`)：
  - 计算中点：`int mid = (l + r) / 2;`
  - 若 `arr[mid] == target`：直接返回索引 `mid`。
  - 若 `target > arr[mid]`：说明 `target` 必然不在 `mid` 及左侧，新的搜索区间应为 `[mid + 1 ... r]`，因此更新 **`l = mid + 1`** (`09:50`)。
  - 若 `target < arr[mid]`：说明 `target` 必然不在 `mid` 及右侧，新的搜索区间应为 `[l ... mid - 1]`，因此更新 **`r = mid - 1`** (`11:10`)。
- **边界终止** (`11:36`)：
  - 当 `l > r` 时，区间 `[l...r]` 为空，说明数组中不存在 `target`，循环结束，返回 `-1`。

### 4. 循环不变量（Loop Invariant）(`11:48`)

- **概念定义**：在循环体执行的全过程中，始终保持为“真”的变量关系或逻辑状态声明。
- **本节示例中的循环不变量**：`"target 如果存在，一定在 [l...r] 闭区间内"`。
- **应用方法**：
  1. 初始化时，确保 `l = 0, r = n - 1` 正确覆盖整个数组范围 `[0 ... n-1]`。
  2. 每次循环迭代，通过更新 `l` 或 `r` 缩小区间，同时**严格保证新区间依然符合该定义**。
  3. 讲师建议：在学习快速排序（分区）、归并排序（合并）、堆（Sift Up/Down）及图论算法时，都应主动寻找并明确其循环不变量。

### 5. 测试用例与验证 (`13:40`)

- **讲师测试方案**：
  - 编写工具函数 `MyUtil::generateOrderedArray(n)`，生成元素为 `0, 1, 2, ..., n-1` 的有序数组。
  - 设置数据规模 $n = 10^6$（100万）。

## 问题与解法

- **问题定义**：在一个已知包含 $n$ 个元素的有序数组 `arr` 中查找目标值 `target` 的位置。
- **输入**：有序数组 `arr[]`、数组长度 `int n`、目标元素 `T target`。
- **输出**：若找到返回目标索引 `int`；若未找到返回 `-1`。
- **简洁代码**（基于视频 05:00–11:48 讲解整理）：

```cpp
#include <iostream>
#include <cassert>

template<typename T>
int binarySearch(T arr[], int n, T target) {
    // 变量定义：在 [l...r] 的闭区间范围内寻找 target
    int l = 0, r = n - 1;

    // 循环不变量：只要 l <= r，[l...r] 区间就依然有效（非空）
    while (l <= r) {
        int mid = (l + r) / 2;
        if (arr[mid] == target) {
            return mid;
        }
        if (target > arr[mid]) {
            l = mid + 1; // target 在 [mid + 1 ... r] 中
        } else {
            r = mid - 1; // target 在 [l ... mid - 1] 中
        }
    }

    return -1; // [l...r] 区间为空，未找到
}
```

## 正确性与不变量

- **变量精确定义**：
  - `l`：当前有效搜索区间的左闭界索引。
  - `r`：当前有效搜索区间的右闭界索引。
- **循环不变量**：
  - 在每次循环开始判定 `while(l <= r)` 之前及循环体内部，若 `target` 存在于原数组中，其索引 $idx$ 必然满足 $idx \in [l, r]$。
- **终止条件与覆盖率**：
  - 区间不断折半缩小，算法必然收敛。
  - 退出循环的唯一条件是 `l > r`（此时闭区间内元素个数为 0），已排查所有可能位置，可安全判定目标不存在。

## 易错点与边界测试

| 风险                                 | 为什么容易错                                                              | 最小测试或反例                                            |
| ------------------------------------ | ------------------------------------------------------------------------- | --------------------------------------------------------- |
| 循环条件漏掉等号写成 `while (l < r)` | 当搜索区间缩小到仅剩 1 个元素（`l == r`）时，直接跳出循环，导致该元素漏检 | 在 `[1, 3, 5]` 中查找 `1` 或 `5`，或者数组仅有 1 个元素时 |
| 边界更新写成 `l = mid` 或 `r = mid`  | 排除中点不彻底，导致区间无法缩小，引发死循环                              | 查找数组中不存在的元素时死循环                            |
| 初始右界 `r = n - 1` 却配错循环逻辑  | 边界定义混乱导致数组越界或漏检索                                          | 搜索目标大于所有数组元素时访问越界                        |
