# 2-3 简单的复杂度分析

## 一句话定位

本节通过 7 种典型代码模式（涵盖单循环、嵌套循环、折半/倍增循环及根号条件循环），系统讲解如何通过控制流分析推导 $O(1)$、$O(n)$、$O(n^2)$、$O(\log n)$、$O(n \log n)$ 及 $O(\sqrt{n})$ 时间复杂度，并揭示了双重循环误判及边界条件缺失等面试常见陷阱。

## 学习目标

- 能根据代码的循环边界、递增/倍增方式准确判断算法的时间复杂度。
- 理解对数复杂度 $O(\log n)$ 中通过换底公式忽略底数的数学依据。
- 辨算双重循环中的常见陷阱，识别非 $O(n^2)$ 的多重循环特例（如内层常数循环、外层对数增长循环）。
- 养成在面试中主动检查代码边界（如 0、负数、小于等于 1 的极端输入）的防错意识。

## 详细笔记

### 1. 常数复杂度 $O(1)$ 与线性复杂度 $O(n)$

- **常数复杂度 $O(1)$** [`00:08`]：
  - **代码范例**：两数交换 `swapTwoInts(int &a, int &b)`。
  - **特征**：画面直接可见，内部仅涉及辅助变量赋值与数据交换，不随任何输入数据规模 $n$ 的增长而变化。
- **线性复杂度 $O(n)$** [`00:30`]：
  - **范例 1（标准单循环）**：`sum(int n)` 求解 $0$ 到 $n$ 的累加和，循环执行 $n+1$ 次，基本操作次数为 $c \cdot n$（$c$ 为常数），属于 $O(n)$。
  - **范例 2（折半线性循环）** [`01:06`]：`reverse(string &s)` 翻转字符串。
    - **讲师分析**：循环条件为 `i < n/2`，实际执行了 $\frac{1}{2}n$ 次 `swap` 操作。
    - **结论**：随着字符串长度 $n$ 增加，消耗时间呈线性增长，常数系数 $\frac{1}{2}$ 在大 O 表示法中忽略，复杂度依然是 $O(n)$。

### 2. 平方复杂度 $O(n^2)$ 及双重循环陷阱

- **平方复杂度 $O(n^2)$ 的严格推导** [`02:12`]：
  - **代码范例**：选择排序 `selectionSort(int arr[], int n)`。
  - **推导过程（讲师手写推导）**：
    - 当 $i=0$ 时，内层比较 $n-1$ 次；
    - 当 $i=1$ 时，内层比较 $n-2$ 次；
    - ……
    - 当 $i=n-1$ 时，内层比较 $0$ 次。
    - **总比较次数**：$(n-1) + (n-2) + \dots + 0 = \frac{(0 + n - 1) \cdot n}{2} = \frac{1}{2}n^2 - \frac{1}{2}n$。
  - **大 O 简化**：忽略低阶项 $-\frac{1}{2}n$ 和常数系数 $\frac{1}{2}$，最终复杂度为 $O(n^2)$。
- **双重循环陷阱：常数内层** [`05:13`]：
  - **代码范例**：`printInformation(int n)` 打印 $n$ 个班级中每班 30 名学生的信息。
  - **分析**：外层循环 $n$ 次，内层循环固定界限为 `j <= 30`（与 $n$ 无关）。
  - **结论**：总基本操作次数为 $30n$，时间复杂度为 $O(n)$，而非看到双重循环就盲目认定为 $O(n^2)$。

### 3. 对数复杂度 $O(\log n)$ 与换底公式

- **折半查找对数推导（二分查找）** [`06:31`]：
  - **代码范例**：`binarySearch(int arr[], int n, int target)`。
  - **讲师推导**：每次未找到目标时均排除一半元素，搜寻范围演变为 $n \to \frac{n}{2} \to \frac{n}{4} \dots \to 1$。
  - **核心数学问题**：$n$ 经过多少次“除以 2”操作后结果等于 1？答案为 $\log_2 n$，因此时间复杂度为 $O(\log n)$。
- **数位处理对数推导（整数转字符串）** [`09:00`]：
  - **代码范例**：`intToString(int num)`，循环内部执行 `s += '0' + num % 10; num /= 10;`，最后执行 `reverse(s)`。
  - **讲师推导**：问题等价于“$n$ 经过多少次‘除以 10’操作后结果等于 0？”答案为 $\log_{10} n$。末尾 `reverse(s)` 耗时与字符串长度（即数位位数 $\log_{10} n$）成正比。
- **为什么 Big-O 可以忽略对数的底数？** [`11:38`]：
  - **讲师给出公式**：根据换底公式：
    $$\log_a N = \log_a b \cdot \log_b N$$
  - **分析者推理**：因为 $\log_a b$ 对于固定底数 $a$ 和 $b$ 而言只是一个常数（例如 $\log_2 10$ 为常数），所以 $\log_a N$ 与 $\log_b N$ 仅相差常数倍（类似于 $2n$ 与 $3n$ 的关系）。
  - **结论**：在 Big-O 复杂度表示中，常数系数被忽略，因此统写作 $O(\log n)$。

### 4. 线性对数复杂度 $O(n \log n)$ 与根号复杂度 $O(\sqrt{n})$

- **线性对数复杂度 $O(n \log n)$** [`14:46`]：
  - **代码范例**：`hello(int n)` 包含两层循环：
    - 外层：`for (int sz = 1; sz < n; sz += sz)` —— 变量 `sz` 每次翻倍（`1, 2, 4, 8...`），循环执行 $\log_2 n$ 次。
    - 内层：`for (int i = 1; i < n; i++)` —— 执行 $n-1$ 次。
  - **结论**：总打印次数为 $n \cdot \log n$ 级别，复杂度为 $O(n \log n)$。
- **平方根复杂度 $O(\sqrt{n})$（素数判定）** [`16:45`]：
  - **代码范例**：`isPrime(int n)` 包含循环 `for (int x = 2; x * x <= n; x++)`。
  - **分析**：终止条件 `x * x <= n` 等价于 $x \le \sqrt{n}$。
  - **结论**：循环最多执行 $\sqrt{n}$ 次，时间复杂度为 $O(\sqrt{n})$。

## 问题与解法

本节未讲解单一算法题，而是通过 7 个典型代码示例展示复杂度分析模式：

### 核心代码模式归纳

```cpp
// 1. O(1) 常数模式
void swapTwoInts(int &a, int &b) {
    int temp = a; a = b; b = temp;
}

// 2. O(n) 线性模式（字符串翻转）
void reverse(string &s) {
    int n = s.size();
    for (int i = 0; i < n / 2; i++)
        swap(s[i], s[n - 1 - i]);
}

// 3. O(n^2) 平方模式（选择排序）
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[minIndex]) minIndex = j;
        swap(arr[i], arr[minIndex]);
    }
}

// 4. O(log n) 对数模式（整数转字符串试例）
string intToString(int num) {
    string s = "";
    while (num) {
        s += '0' + num % 10;
        num /= 10;
    }
    reverse(s);
    return s;
}

// 5. O(n log n) 组合模式（外层倍增）
void hello(int n) {
    for (int sz = 1; sz < n; sz += sz)     // 外层执行 log n 次
        for (int i = 1; i < n; i++)        // 内层执行 n 次
            cout << "Hello, Algorithm!" << endl;
}

// 6. O(sqrt(n)) 根号模式（试除法判素数试例）
bool isPrime(int n) {
    for (int x = 2; x * x <= n; x++)
        if (n % x == 0) return false;
    return true;
}
```

## 正确性与不变量

- **循环变量语义**：
  - `reverse`: `i` 表示前端待交换字符的索引，对称位置为 `n - 1 - i`。
  - `hello`: 外层 `sz` 代表子组/块的长度，按 $2^k$ 级数递增；内层 `i` 进行线性扫描。
  - `isPrime`: `x` 为可能整除 $n$ 的因数候选，由于因数成对出现（若 $a \cdot b = n$，必有一个 $\le \sqrt{n}$），故只需检验到 $\sqrt{n}$。
- **终止条件与边界漏洞（讲师明确强调）** [`13:50`, `18:00`]：
  - `intToString`: 若输入 `num = 0`，`while(num)` 条件直接不成立，返回空字符串（正确应为 `"0"`）；若输入 `num < 0`，取模及整除逻辑会出错。
  - `isPrime`: 若输入 $n \le 1$（如 $n=1$ 或负数），循环条件直接跳过并返回 `true`，导致误判 1 或负数为素数。

## 面试视角

- **面试前应澄清的问题**：遇到嵌套循环时，先澄清变量的更新规则（是 `i++`、`sz += sz` 还是固定常数）。
- **推荐的口头表达顺序**：
  1. 明确循环变量的初始值、终止条件与更新步长；
  2. 计算基本操作的总执行次数表达公式；
  3. 运用 Big-O 规则省略低阶项与常数系数，给出最终复杂度。
- **面试官可能追问**：
  - “为什么 Big-O 表示法中对数复杂度不写底数（如 $O(\log_2 n)$ 写成 $O(\log n)$）？”
    - **答**：利用对数换底公式 $\log_a N = \log_a b \cdot \log_b N$，不同底数的对数之间仅相差常数因子 $\log_a b$，在 Big-O 表示法中常数因子被省略。
  - “写完代码后，这段代码有哪些边界 Bug？”
    - **答**：例如整数转字符串未处理 $0$ 和负数；素数判断未拦截小于等于 1 的数。
- **优化方向**：素数判断在试除到 $\sqrt{n}$ 的基础上，可先特判偶数，使循环步长变为 2，从而减少一半的试除次数（讲师点到为止，留作思考题）[`18:30`]。

### 记忆卡

- **Q: 对数换底公式与 Big-O 底数忽略的关系？**
  - **A**: $\log_a N = \log_a b \cdot \log_b N$。对于常数底数 $a, b$，$\log_a b$ 为常数因子。大 O 表示法中忽略常数系数，因而不同底数的对数复杂度统一记为 $O(\log n)$。
- **Q: 如何快速判断双重循环的复杂度类别？**
  - **A**: 观察循环步长：若两层均线性递增/递减且与 $n$ 相关，为 $O(n^2)$；若一层界限为与 $n$ 无关的常数，为 $O(n)$；若一层步长翻倍（如 `sz += sz`），则为 $O(n \log n)$。
- **Q: 素数试除法 `x * x <= n` 的时间复杂度及边界陷阱是什么？**
  - **A**: 时间复杂度为 $O(\sqrt{n})$；陷阱是若漏掉对 $n \le 1$（如 0, 1, 负数）的显式拦截，会错误返回 `true`。
