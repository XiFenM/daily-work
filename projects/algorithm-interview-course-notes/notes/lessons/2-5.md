# 2-5 递归算法的复杂度分析

## 一句话定位

本节系统讲解递归算法时间复杂度的通用分析方法，区分“单次递归调用”与“多次递归调用”两类模式，通过递归深度与递归树模型建立对指数级、对数级与 $O(n \log n)$ 复杂度的直观理解。

## 学习目标

- 纠正“只要有递归复杂度就是 $O(n \log n)$”的常见误区；
- 掌握单次递归调用算法的通用复杂度公式 $O(T \times \text{depth})$；
- 理解快速幂（`pow`）算法如何将 $x^n$ 的计算时间复杂度从 $O(n)$ 优化至 $O(\log n)$；
- 掌握多次递归调用算法的“递归树”节点计数分析法，理解指数级 $O(2^n)$ 的产生机制；
- 能从“递归树深度”与“每层处理数据总量”两个维度区分指数级递归与归并排序 $O(n \log n)$ 的本质差异；
- 了解主定理（Master Theorem）的应用定位及其在算法面试中的掌握边界。

## 详细笔记

### 1. 澄清误区 `00:00`

- **讲师明确说明**：许多初学者受归并排序（Merge Sort）、快速排序（Quick Sort）影响，误以为“只要使用了递归，时间复杂度大概就是 $O(n \log n)$”。这是不对的，对于递归算法必须具体问题具体分析。

---

### 2. 递归中进行一次递归调用的复杂度分析 `00:45`

- **模式特征**：在递归函数体内部，**最多只进行一次**递归调用。
- **通用分析公式 `02:48`**：
  $$\text{总时间复杂度} = O(T \times \text{depth})$$
  其中：
  - $\text{depth}$ 为递归调用的最大深度；
  - $T$ 为每个递归函数内部除了递归调用外，执行其他操作的复杂度。

- **经典示例分析**：
  1. **递归版二分查找 `binarySearch` (`00:57`)**：
     - **画面直接可见**：代码内部根据 `arr[mid]` 与 `target` 关系，分支执行左侧或右侧的 `binarySearch`，即每次仅触发一次递归。
     - **分析**：数据规模每次减半，递归深度为 $\log n$；函数内部非递归操作均为 $O(1)$，故总复杂度为 $O(1 \times \log n) = O(\log n)$。
  2. **递归累加求和 `sum(n)` (`03:21`)**：
     - **画面直接可见**：代码逻辑为 `return n + sum(n - 1)`，终止条件 `n == 0`。
     - **分析**：每次规模减 1，从 $n$ 到 $0$ 共调用 $n$ 层，递归深度为 $n$；内部非递归耗时 $O(1)$，总复杂度为 $O(n)$。
  3. **快速幂算法 `pow(x, n)` (`04:01`)**：
     - **画面直接可见**：代码先计算 `double t = pow(x, n / 2)`，若 $n$ 为奇数返回 `x * t * t`，偶数返回 `t * t`。
     - **讲师明确说明**：关键在于用变量 `t` 保存了递归结果并复用（乘以自身），从而避免了两次重复递归。
     - **分析**：每次指数 $n$ 减半，递归深度为 $\log n$；单次耗时 $O(1)$，总复杂度为 $O(\log n)$。对比暴力连乘的 $O(n)$ 复杂度，性能提升巨大（`06:16` 提到回顾上一节关于 $O(n)$ 与 $O(\log n)$ 的巨大差距）。
     - **讲师思考题 (`06:38`)**：代码中使用了 `assert(n >= 0)`，若要支持计算负数次方 $x^{-n}$，该如何改写函数？

---

### 3. 递归中进行多次递归调用的复杂度分析 `06:49`

- **模式特征**：在递归函数体内部，存在**多次**递归调用。
- **分析核心 `07:30`**：
  - **讲师明确说明**：单次递归时“递归深度即调用次数”；但多次递归时，递归深度与总调用次数不再等价，此时核心在于**计算调用的总次数**。

- **双重递归示例 `f(n)` (`06:57`)**：
  - **画面直接可见**：代码为 `return f(n - 1) + f(n - 1)`，终止条件为 `n == 0` 返回 `1`。
  - **递归树模型分析 (`07:58`)**：
    - 根节点 `f(3)`：调用 2 次 `f(2)`；
    - 1 层：2 个 `f(2)`，各调用 2 次 `f(1)`，共 4 个 `f(1)`；
    - 2 层：4 个 `f(1)`，各调用 2 次 `f(0)`，共 8 个 `f(0)`；
    - 3 层：`f(0)` 触底返回。
  - **节点总数推导 (`08:38`)**：
    - 层数为 $n$，各层节点数为 $2^0, 2^1, 2^2, \dots, 2^n$；
    - 等比数列求和：$1 + 2 + 4 + \dots + 2^n = 2^{n+1} - 1$；
    - **时间复杂度**：$O(2^n)$（指数级）。
  - **讲师强调 (`09:47`)**：
    - 指数级算法极慢，对数据规模敏感。$n=20$ 时约百万次操作；$n=30$ 时约 10 亿次，家用电脑已运行极慢。
    - **优化方向**：可尝试剪枝（Backtracking）或利用问题性质转换为动态规划（Dynamic Programming）降至多项式级别。
    - **推论应用 (`10:41`)**：许多搜索问题会展开成树形递归；遍历成本与实际展开的节点数成正比。当分支数固定而树深度随 $n$ 增长、又缺乏剪枝时，节点数可能达到指数级。不能据此断言所有“树的建立与遍历”都必然是指数复杂度。

---

### 4. 对比反思：归并排序为何是 $O(n \log n)$？ `10:58`

- **问题抛出**：归并排序 `mergeSort` 体内也调用了两次递归，为什么复杂度不是 $O(2^n)$ 而是 $O(n \log n)$？
- **讲师对比分析 (`11:12`)**：
  1. **树深度不同**：`f(n)` 每次规模减 1，树深度是 $n$；归并排序每次规模减半（`mid = (l+r)/2`），树深度是 $\log n$。
  2. **单节点处理数据量递减 (`11:25`)**：
     - **画面直接可见**：对于 8 个元素的归并排序：
       - 第 0 层：1 个节点，处理规模 8；
       - 第 1 层：2 个节点，各处理规模 4；
       - 第 2 层：4 个节点，各处理规模 2；
       - 第 3 层：8 个节点，各处理规模 1；
     - 每层所有节点处理的数据规模总和均为 $n$。由于合并操作 `merge` 是 $O(\text{规模})$ 的，因此**每层总耗时均为 $O(n)$**。
  3. **结论**：$\text{层数} \times \text{每层总耗时} = \log n \times O(n) = O(n \log n)$。

---

### 5. 递归复杂度分析的通用数学工具：主定理（Master Theorem） `13:53`

- **讲师明确说明**：
  - 主定理是分析常见分治递推式 $T(n) = a T(n/b) + f(n)$ 的通用数学工具。
  - 面试中通常**不会直接考察主定理**，掌握本节讲解的“递归树节点计数”与“单次递归公式”已足够涵盖绝大多数算法面试场景。
- **分析者校准**：主定理只适用于满足相应形式和正则条件的递推式，并不能覆盖所有递归程序；不符合条件时仍需使用递归树、代入法或其他分析方法。

## 问题与解法

本节通过多个经典递归函数演示复杂度分析方法，代码控制流归纳如下：

### 1. 递归二分查找（单次递归）

```cpp
int binarySearch(int arr[], int l, int r, int target) {
    if (l > r) return -1; // 终止条件
    int mid = l + (r - l) / 2;
    if (arr[mid] == target) return mid;
    else if (arr[mid] > target)
        return binarySearch(arr, l, mid - 1, target); // 单次递归
    else
        return binarySearch(arr, mid + 1, r, target); // 单次递归
}
```

### 2. 快速幂算法（单次递归优化）

```cpp
double pow(double x, int n) {
    assert(n >= 0);
    if (n == 0) return 1.0; // 终止条件
    double t = pow(x, n / 2); // 关键：仅递归一次，复用 t
    if (n % 2) return x * t * t; // 奇数次方补乘一个 x
    return t * t;
}
```

### 3. 双重指数递归（多次递归）

```cpp
int f(int n) {
    assert(n >= 0);
    if (n == 0) return 1;
    return f(n - 1) + f(n - 1); // 两次递归调用，引发指数级展开
}
```

## 正确性与不变量

- **快速幂递归语义**：`pow(x, n)` 正确计算 $x^n$。依据数学公式：
  $$x^n = \begin{cases} (x^{n/2})^2 & n \text{ 为偶数} \\ x \cdot (x^{n/2})^2 & n \text{ 为奇数} \end{cases}$$
- **终止条件保证**：
  - 二分查找：当搜索区间空（$l > r$）时终止，确保不发生死循环；
  - 快速幂与 `f(n)`：当 $n = 0$ 时递归触底返回，保证有限步内终止。

| 算法 / 函数示例      | 时间复杂度    | 空间复杂度                      | 输入规模与成立条件                                  | 来源 / 依据  |
| -------------------- | ------------- | ------------------------------- | --------------------------------------------------- | ------------ |
| 递归二分查找         | $O(\log n)$   | $O(\log n)$                     | 数组有序，单次递归，每次区间减半                    | 讲师明确说明 |
| 递归求和 `sum`       | $O(n)$        | $O(n)$                          | $n \ge 0$，单次递归，每次规模减 1                   | 讲师明确说明 |
| 快速幂 `pow`         | $O(\log n)$   | $O(\log n)$                     | $n \ge 0$，单次递归，复用 `pow(x, n/2)`             | 讲师明确说明 |
| 双重递归 `f(n)`      | $O(2^n)$      | $O(n)$                          | $n \ge 0$，多次递归，每次规模减 1                   | 讲师明确说明 |
| 归并排序 `mergeSort` | $O(n \log n)$ | $O(n)$ [分析者补充：含临时数组] | 规模为 $n$ 的数组，分治树深度 $\log n$，每层 $O(n)$ | 讲师明确说明 |

## 面试视角

- **澄清问题**：被问及递归算法复杂度时，应首先确认是“单次递归”还是“分治/多次递归”。
- **推荐表达顺序**：
  1. 指出该递归函数体内每次调用了几次自身；
  2. 分析递归树的深度（如 $n$ 或 $\log n$）；
  3. 计算每层操作的总耗时或总节点数；
  4. 给出最终 Big-O 结论。
- **面试官可能的追问**：
  - _追问_：“如果在快速幂中不写 `t = pow(x, n/2)`，直接写 `pow(x, n/2) * pow(x, n/2)`，复杂度是多少？”
  - _回答_：这会导致单次递归变成两次递归调用，复杂度将从 $O(\log n)$ 退化至 $O(n)$。

| 风险                     | 为什么容易错                                                                    | 最小测试或反例                                        |
| ------------------------ | ------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 快速幂未复用递归结果     | 以为写成 `pow(x, n/2) * pow(x, n/2)` 同样是分治，忽略了重复计算带来的树节点爆炸 | $n=100$ 时，测试递归调用次数是否增加                  |

### 记忆卡

- **问题**：单次递归调用的通用时间复杂度公式？
  **简答**：$O(T \times \text{depth})$，其中 $T$ 为单次函数内部非递归耗时，$\text{depth}$ 为递归最大深度。
- **问题**：满二叉递归树节点总数与指数级复杂度的对应关系？
  **简答**：深度为 $n$ 的满二叉递归树，节点总数为 $\sum_{i=0}^n 2^i = 2^{n+1}-1$，故时间复杂度为 $O(2^n)$。
- **问题**：快速幂算法计算 $x^n$ 的复杂度及核心思想？
  **简答**：时间复杂度 $O(\log n)$。核心在于利用 $x^n = (x^{n/2})^2$，每次将指数减半，仅做单次递归并复用计算结果。
